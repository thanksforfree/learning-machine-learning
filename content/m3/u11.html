Reinforcement learning (RL) baaki sab se alag kaise hai?

Kutte ko trick sikhaate ho? Tum har pal nahi bolte “ab pair 3 cm upar”. Bas sahi karta hai to biscuit, galat pe biscuit nahi. Dheere dheere woh khud samajh jaata hai kya karna hai. RL mein bhi computer ko exact answer nahi dete — bas reward dete hain.

Return aur discount factor γ — “aaj ka ₹100 kal ke ₹100 se better”

Tumhe koi bole: ₹100 abhi lo, ya ₹100 ek saal baad? Abhi wala lo! Door ka reward thoda kam valuable lagta hai. RL mein har agle step ka reward γ (gamma) se multiply hota hai. γ = 0.5 lete hain (samjhane ke liye; asli mein aksar 0.9–0.99).

Return = R₁ + γ·R₂ + γ²·R₃ + γ³·R₄ + …
  • R₁ = abhi wali state ka reward, R₂ = agle step ka, …

Interesting, na? Ghar 3 se cake (50) ke liye left jaana best. Par ghar 4 se cake bahut door hai — discount ki wajah se paas wali chai (20) better. γ agent ko “jaldi reward lo” wali soch deta hai.

Policy (π) — har state ke liye plan

Policy = ek rule-book: “is state mein ye action lo”. Upar ke hisaab se best policy: ghar 2 → left, ghar 3 → left, ghar 4 → right. RL ka goal: woh policy dhundho jo return maximum kare.

MDP (Markov Decision Process): Ye poora setup — states, actions, rewards, γ, policy — isko MDP kehte hain. “Markov” ka matlab: agla state/reward abhi ki state aur tumhare chune action pe depend karta hai; usse pehle ka poora raasta alag se jaanne ki zaroorat nahi. Jaise Ludo mein ab tum kis square pe ho aur kaunsi chaal chal rahe ho, wahi aage ka hisaab tay karta hai.

γ badalne se policy ka mood badalta hai

γ bas formula ka symbol lag raha. Isse behaviour sach mein badalta hai?

Bilkul. γ chhota matlab “jaldi reward do”. γ bada matlab “door ka reward bhi important”. Same street example mein dekho.

Ghar 4 se do options: right jao to ek step baad chai reward 20. Left-left-left jao to 3 steps baad cake reward 50.

Same world, different γ, different decision. Isliye γ hyperparameter hai — agent kitna future-minded ho, ye set karta hai.

Yaad rakhna: RL = agent action leta hai, reward milta hai, aur woh policy seekhta hai jo discounted total reward (return) maximum kare.

Dimaag mein aaye sawaal

RL kahan use hota hai?

Robots ko chalna sikhana, games (chess, video games), factory optimization, stock trading ke experiments, helicopter/drone control. Supervised learning se kam jagah, par exciting.

Negative reward bhi hota hai?

Haan. Jaise robot deewar se takraye to −10, ya fuel jalaye to −0.3. Agent seekhta hai ki aise kaam kam kare, warna total return ka mood kharab.

γ = 1 rakha to?

Door aur paas ka reward barabar. Tab ghar 4 se bhi cake (50) best lagega. γ chhota → agent “abhi ka socho” wala, γ bada → “lamba socho” wala.

Reward state ka hota hai ya action ka?

Notation course/book pe depend karta hai: R(s), R(s,a), ya R(s,a,s'). Idea same hai — action ke baad environment se feedback milta hai.
