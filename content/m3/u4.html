Anomaly detection kya hota hai? Naam se detective series lag rahi.

Bilkul detective vibe hai. Mummy ko pata hai tum aam taur pe raat 9 baje ghar aate ho. Ek din 2 baje aaye — turant pakde gaye. Kyunki unhe “normal” pata tha, to “ajeeb” turant dikh gaya. Anomaly detection bhi pehle normal seekhta hai, phir bahut alag case ko flag karta hai.

Real life mein kahan?

Factory mein motor: normal temperature aur vibration pata hai. Naya motor bahut garam aur bahut hil raha? Check karo, kharab ho sakta hai. Bank: tumhara card roz ₹500 kharch karta hai, achanak raat 3 baje doosre desh mein ₹2 lakh? Fraud alert. Website: ek account ek minute mein 500 baar login try kare? Ajeeb.

Normal kaisa dikhta hai — bell curve se

Maan lo 1000 achhe motors ka temperature record kiya. Average μ = 60°C, σ = 5°C. Zyadatar motors 50–70°C ke beech (μ ± 2σ). 80°C dekh ke system bolega: “bhai, ye aam nahi hai.”

Gaussian (normal) distribution ke 2 knobs

μ (mean)Ghanta kahan khada hai. μ badlo → poori curve left/right khisakti.
σ (std deviation)Ghanta kitna chauda. σ chhota → patla aur uncha. σ bada → chauda aur neecha. (Total area hamesha 1.)

p(x) = curve ki height us value ke paas — ise probability density kehte hain. Height zyada ho to uske aas-paas ki values zyada aam hoti hain; ek exact value ki probability nahi. Formula mein e aur σ aate hain; pehli baar formula dekh ke aankh thodi phadakti hai, but library (scipy ya NumPy) calculate kar degi.

z-score se pehla doubt clear karo

4σ door rare bol rahe ho. Ye σ door kaise nikaala?

Value se mean ghatao, phir σ se divide karo. Ye z-score hai: average se kitne standard deviations door.

z-score = (x − μ) / σ
  • μ = normal average, σ = normal spread.

Bell curve mein dono side rare ho sakte hain. Motor bahut garam bhi problem, suspiciously thandi bhi sensor issue ho sakti hai.

One-sided vs two-sided ajeeb

Anomaly sirf zyada high nahi hota. Bahut low bhi suspicious ho sakta hai.

FeatureToo lowToo high
TemperatureSensor dead?Overheating?
Login attemptsMaybe normalAttack?
TrafficService down?Bot flood?

Feature ka domain samjho. Har low value anomaly nahi, har high value bhi nahi — context matters.

Yaad rakhna: Normal data se μ aur σ seekho. Nayi value ka p(x) bahut kam = ajeeb = anomaly.

Dimaag mein aaye sawaal

Anomaly hamesha kharab cheez hai?

Nahi — bas “aam se alag”. Ek genuine bada kharcha bhi flag ho sakta hai. Isliye aam taur pe alert insaan check karta hai, system turant saza nahi deta.

Training data mein kharab motors bhi hon to?

Thode se hon to chalta hai, par training mostly normal examples se honi chahiye. Warna model “normal” ki photo hi dhundhli bana lega.

Gaussian fit na ho to kya?

Feature transform try karo: log(x), square root, ya x^(1/3). Agar phir bhi weird hai, different model ya extra features socho.

Har feature ko bell curve banana zaroori?

Perfect bell zaroori nahi, par roughly single peak aur sensible spread helpful hai. Bahut skewed feature p(x) ko misleading bana sakta hai.
