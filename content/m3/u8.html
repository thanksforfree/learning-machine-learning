Naya user aaya, usne ek bhi movie rate nahi ki. Usko kya dikhaayenge — blank screen?

Agar kuch na karein to problem hai. Uski cost mein koi rating nahi, sirf regularization hai — jo weights ko 0 ki taraf dhakelta hai. To w = 0, b = 0 → har movie ka predicted rating 0 star! Matlab “isse kuch pasand nahi” — bilkul bekaar.

To?

Mean normalization. Pehle har movie ka average rating nikaalo aur ratings mein se ghata do. Model “average se kitna upar/neeche” seekhe. Predict karte waqt average wapas jod do. Naye user ke liye w = 0 → prediction = movie ka average. Kaafi samajhdaar default!

TensorFlow mein — custom training loop

Yahan cost function khud likhte hain aur TensorFlow ka GradientTape slopes nikaalta hai (auto-diff):

optimizer = tf.keras.optimizers.Adam(learning_rate=0.1)
for step in range(200):
    with tf.GradientTape() as tape:
        cost = cofi_cost(X, W, b, Y_norm, R, lam)   # apna cost function
    grads = tape.gradient(cost, [X, W, b])          # slopes automatic
    optimizer.apply_gradients(zip(grads, [X, W, b]))

(R = kaunse table cells rated hain, 1/0. Y_norm = mean-normalized ratings.) Isse ek cool baat samajh aati hai: TensorFlow sirf neural networks ke liye nahi — koi bhi cost likho, woh gradient nikaal sakta hai.

Milti-julti movies dhundhna

Seekhe gaye features x ab movie ki “personality” hain. Movie A jaisi movie chahiye? Woh movie dhundho jiska x, A ke x ke sabse paas ho: doori = Σ (xₖᴬ − xₖᴮ)². “Isko dekhne walon ne ye bhi dekha.”

Dimaag mein aaye sawaal

Movie ke average se normalize karein ya user ke?

Naye user problem ke liye movie (row) ka average. Agar nayi movie ki problem zyada important ho to user (column) ka average bhi le sakte ho.

model.fit kyu nahi use kiya?

Ye standard neural network layers wala model nahi hai, isliye apna cost aur apna loop likha. GradientTape isi custom kaam ke liye hai — jab ready-made dabba fit na aaye, apna dabba banao.

Mean normalization ke baad rating negative kyu ho sakti hai?

Negative ka matlab “movie average se neeche”. Ye final star rating nahi, centered signal hai. Prediction ke waqt average wapas jod dete hain.

Related items mein user taste use hota hai?

Basic similar-items search sirf item vectors use karta hai. Personalized recommendation mein user vector/weights bhi include hote hain.
