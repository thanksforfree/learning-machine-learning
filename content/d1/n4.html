Gradient descent recap

Training ka goal cost J ko kam karna hai. Agar kisi weight w ke hisaab se slope dw positive hai, w badhane se cost badhegi. To w ko thoda ghatao. Agar slope negative hai, w badhao. Minus sign direction sambhal leta hai.

w := w − α · dw b := b − α · db
  • α = learning rate, kadam ka size
  • dw = dJ/dw, cost ka slope w ke respect mein
  • := = update karke naya value rakho

Derivative ko chhote number se check karna

Derivative ka matlab: input ko thoda sa hilao, output kitna badla. Agar tip = 5s hai, s ko 0.001 badhao, tip 0.005 badhegi. Slope = 0.005 / 0.001 = 5. Itna sa “hila ke dekho” test beginners ke liye bahut useful hai.

dvar notation ko receipt se jodo

Bill graph mein dp ka matlab “price mein chhota change final bill ko kitna change karega.” Neural network mein bhi dw ka matlab “weight badalne se cost ka kya asar.” Naam short hai, par sentence lamba padho to clarity aati hai.

Dhyan rakhna: Forward values cache nahi kiye to backward mein problem hogi. dJ/dq nikaalne ke liye p aur t ke forward values chahiye the.
Yaad rakhna: Computation graph formula ko tukdon mein todta hai; backprop wahi tukde ulte order mein slope ke saath chalata hai.

Dimaag mein aaye sawaal

dvar naam weird kyu hai?

Ye shorthand hai. da ka matlab a ka chhota badlav nahi, course notation mein dJ/da hai. Context se padhna.

Gradient descent har baar cost kam karega?

Agar learning rate reasonable hai to aam taur pe. Bahut bada α ho to cost uchhal ke badh sakti hai.

Computation graph manually banana zaroori?

Libraries khud banati hain. Par intuition se tum shape aur gradient bugs pakad paoge.

Bill example mein dJ/dq = 126 ka unit kya hai?

Ye “rupees per extra item” jaisa hai. Quantity 1 badhe to total bill ₹126 badhega, given current price ₹120 aur tax factor 1.05.

Backward pass mein values forward se kyu chahiye?

Local slopes current values pe depend kar sakte hain. Bill example mein dJ/dq = t×p tha, to p aur t ke forward values chahiye. Isi liye cache important hai.
