Sigmoid vs tanh

Sigmoid output 0 se 1 mein deta hai, isliye binary output layer ke liye useful. Hidden layer mein tanh aksar sigmoid se better hota hai kyunki tanh ka output −1 se 1 mein hota hai, zero ke aas-paas centred. Isse next layer ko balanced inputs milte hain.

SigmoidRange 0..1. Probability jaisa. Hidden mein saturation problem ho sakti hai.
tanhRange −1..1. Zero-centred. Hidden layers mein sigmoid se usually nicer.
sigmoid: a = 1/(1+e⁻ᶻ) tanh: a = (eᶻ − e⁻ᶻ)/(eᶻ + e⁻ᶻ)
  • a activation output hai
  • z weighted sum hai

ReLU aur Leaky ReLU

ReLU negative z pe 0, positive z pe z. Simple, fast, aur positive side pe slope 1, isliye deep networks mein gradients zyada der tak bach sakte hain. Leaky ReLU negative side ko bilkul dead nahi karta; chhota slope, jaise 0.01, de deta hai.

ReLU(z) = max(0, z) LeakyReLU(z) = max(0.01z, z)
  • hidden layers mein ReLU common default
  • binary output mein sigmoid, kyunki probability chahiye

Non-linear activation zaroori kyu?

Agar har layer sirf linear ho: A = W X + b. Do linear transformations combine hoke ek badi linear transformation ban jaati hain. Matlab depth ka fayda gaya. Non-linearity network ko curves, boundaries, complex patterns banane ki ijazat deti hai.

def relu(Z):
    return np.maximum(0, Z)

def relu_backward(dA, Z):
    dZ = dA.copy()
    dZ[Z <= 0] = 0        # negative side ka slope 0
    return dZ

Dimaag mein aaye sawaal

ReLU z=0 pe derivative kya?

Technically undefined. Practice mein 0 ya 1 choose kar lo, farak nahi padta kyunki exact 0 rare hota hai.

Regression output ke liye kya activation?

Agar output any real number ho sakta hai to linear. Agar non-negative chahiye, ReLU try kar sakte ho.

Leaky ReLU hamesha ReLU se better?

Nahi. Kabhi help karta hai, kabhi same. Default ReLU se start karna safe hai.

tanh zero-centred hone se kya fayda?

Next layer ko positive aur negative dono signals milte hain. Isse optimization kabhi-kabhi balanced hoti hai compared to sigmoid hidden activations jo mostly positive hoti hain.

Dead ReLU kya hota hai?

Agar neuron hamesha negative z deta rahe, ReLU output 0 aur derivative 0 rahega. Phir woh neuron update se barely recover karta hai. Leaky ReLU kabhi-kabhi help karta hai.
