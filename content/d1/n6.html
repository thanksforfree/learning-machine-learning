Loop vs np.dot

Vectorization ka matlab hai loops ko matrix/vector operations mein badalna. Python ka loop interpreter se guzarta hai; np.dot optimized low-level code use karta hai. Same maths, bas execution ka raasta tez.

Z = wᵀX + b A = σ(Z)
  • X shape (nₓ, m), har column ek example
  • wᵀ shape (1, nₓ)
  • Z aur A shape (1, m), saare examples ke scores/chances

Forward pass numbers ke saath

w = [1, −2], b = 0.5, aur X mein 3 examples columns mein:

Examplexwᵀx + b
1[1, 2]1 − 4 + 0.5 = −2.5
2[3, 1]3 − 2 + 0.5 = 1.5
3[0, 4]0 − 8 + 0.5 = −7.5
Z = np.dot(w.T, X) + b      # b har column mein broadcast
A = 1 / (1 + np.exp(-Z))    # shape (1, m)
dZ = A - Y
dw = np.dot(X, dZ.T) / m
db = np.sum(dZ) / m

Backward pass vectorized

dZ = A − Y dw = X · dZᵀ / m db = (1/m) × Σ dZ
  • dZ shape (1, m)
  • X · dZᵀ shape (nₓ, 1), exactly w jaisa
  • db ek number hai, kyunki b ek number hai

Mini example: X = [[1,2,0],[0,1,3]], A = [0.2,0.7,0.1], Y = [0,1,0]. To dZ = [0.2, −0.3, 0.1].

Broadcasting: b har column mein kaise joda?

Z shape (1, m) hai, b scalar. NumPy scalar ko automatically m columns tak repeat jaisa treat karta hai. Ye convenient hai, par shapes galat hon to silent bug bhi de sakta hai. Isliye assert lagao.

assert X.shape == (n_x, m)
assert w.shape == (n_x, 1)
assert Y.shape == (1, m)
assert dw.shape == w.shape

Rank-1 array wali galti

NumPy mein shape (5,) na row hai na column. Ye beech ka ajeeb creature hai. Deep learning code mein column vector chahiye to (5,1), row chahiye to (1,5). reshape use karo.

Ek full iteration bina example-loop

Vectorized training mein ek iteration ka flow compact ho jaata hai: Z banao, A banao, dZ nikalo, dw/db nikalo, update karo. Sirf shapes check karte raho. Ye style baad mein deep network layers mein bhi repeat hoga.

StepFormulaShape

Dhyan rakhna: np.random.randn(5) se rank-1 array banta hai. Prefer np.random.randn(5, 1). Shape print karo, warna dot product kabhi-kabhi surprise dega.
Yaad rakhna: Examples ko columns mein rakho, phir one dot product se poore batch ka forward-backward ho jaata hai.

Dimaag mein aaye sawaal

Kya iterations wala loop bhi hata denge?

Nahi. Har gradient descent step repeat karna padega. Hum examples/features wale inner loops hata rahe hain.

Broadcasting hamesha achhi cheez hai?

Powerful hai, par dangerous bhi. Galat shape silently expand ho sakti hai. Assertions dost hain.

dw ka shape w jaisa kyu hona chahiye?

Update w := w − αdw tabhi possible hai jab dono same shape hon. Gradient hamesha us parameter ke shape ka hota hai.

np.dot aur @ same hain?

2D arrays ke liye mostly matrix multiply jaisa behavior hai. Course mein np.dot likha mil sakta hai; modern Python mein @ bhi common hai. Shapes phir bhi same rules follow karte hain.

Broadcasting bug ka sign kya hota hai?

Code run ho jaata hai par output shape unexpected hota hai, ya cost weird behave karti hai. Isliye operation ke baad assert shape lagana boring par powerful habit hai.
