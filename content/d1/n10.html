L-layer network dekh ke lagta hai ab har layer ka alag formula hoga.

Good news: nahi. Same block repeat hota hai: Z = WA + b, phir activation.

To depth ka code copy-paste nahi, loop?

Bilkul. Layers pe loop bilkul normal hai. Hum bas examples/features pe slow loops avoid karte hain.

Mera main bug shapes hota hai. Kabhi W ulta, kabhi A ulta.

Aaj shapes ko train timetable ki tarah padhenge. Platform galat hua to train nahi milegi. Shape galat hua to dot product nahi chalega.

Ek rule yaad rahe to?

W[l] current layer ki rows aur previous layer ke columns: (n[l], n[l−1]). Isko pakad lo, aadhe bugs gaye.

Notation: L, n[l], a[l]

L total layers count hai, input layer ko chhod ke. n[l] layer l mein units ki ginti. a[l] layer l ka activation. Aur a[0] = x. Last activation a[L] = ŷ.

Z[l] = W[l] A[l−1] + b[l] A[l] = g[l](Z[l])
  • l = 1 se L tak
  • g[l] = layer l ki activation; last layer mein sigmoid ho sakta hai
  • A[l−1] = previous layer ka output, current layer ka input

Shapes ka rule

Dimensions deep network debugging ka seatbelt hai. Agar layer l mein n[l] units aur previous layer mein n[l−1] units, to W[l] shape (n[l], n[l−1]) hota hai. Bias b[l] (n[l], 1). m examples ke liye Z[l] aur A[l] shape (n[l], m).

Layers pe for-loop theek hai

Forward propagation mein hidden layers ke liye loop lagana clean hai. Har layer previous A leti hai. Last layer sigmoid, beech mein ReLU. Ye loop examples pe nahi, architecture pe hai.

A = X
for l in range(1, L):
    Z = np.dot(W[l], A) + b[l]
    A = relu(Z)
ZL = np.dot(W[L], A) + b[L]
AL = sigmoid(ZL)          # final probability

Backward shapes bhi same logic

Jo parameter update hoga, gradient usi shape ka. dW[l] W[l] jaisa, db[l] b[l] jaisa. dA[l−1] previous activation A[l−1] jaisa. Agar shape match nahi, formula ya transpose galat hai.

Dimension debugging habit

Har layer ke forward ke baad assert lagana boring lag sakta hai, par ye tumhe hours bachata hai. Especially jab L layers ho, ek transpose galat hua to error 4 layers baad dikhega. Assert wahi pe pakad leta hai jahan bug paida hua.

assert W[l].shape == (layer_dims[l], layer_dims[l-1])
assert b[l].shape == (layer_dims[l], 1)
assert A[l].shape == (layer_dims[l], m)
Dhyan rakhna: W[l] ko (n[l−1], n[l]) bana doge to forward mein transpose ka jungle shuru ho jayega. Course convention pakka rakho: current units rows mein.
Yaad rakhna: Deep network koi naya monster nahi; same Z = WA + b block L baar repeat hota hai.

Dimaag mein aaye sawaal

L mein input layer count hoti hai?

Nahi. Agar 3 hidden aur 1 output layer hai, L = 4.

Har hidden layer same activation use kare?

Usually ReLU hidden layers mein default start. Kabhi tanh ya leaky ReLU try kar sakte ho.

Dimensions yaad kaise rahein?

W[l] maps A[l−1] to A[l]. Output rows n[l], input rows n[l−1]. Isliye W[l] = (n[l], n[l−1]).

Layers pe loop slow nahi hoga?

Layers ki count usually dozens hoti hai, examples lakhon. Big speed gain examples/features vectorize karne se aata hai. Layers loop readable aur practical hai.

b[l] ko (n[l], m) kyu nahi rakhte?

Bias har neuron ka ek shared offset hai, examples ke liye same. Shape (n[l],1) rakho, broadcasting use karke m columns mein add ho jaata hai.
