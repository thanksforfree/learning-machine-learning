Dost, NumPy mein shape error aata hai to lagta hai computer mujhse lad raha hai.

Haan, Level 3 ka pehla boss yahi hai: shape. Deep learning mein numbers se zyada tables ki size matter karti hai.

Par (3,), (3,1), (1,3) — teeno mein 3 numbers hi hain na?

Numbers same, par table ka posture alag. Ek loose list, ek seedha column, ek leti hui row. NumPy inke saath alag behave karta hai.

(m,), (m,1), (1,m) — chhota farak, bada bug

ShapeDikhta kaiseBeginner translation
(3,)[10, 20, 30]Rank-1 array: na row, na column. Thoda “latka hua”.
(3, 1)[[10], [20], [30]]3 rows, 1 column. Proper column vector.
(1, 3)[[10, 20, 30]]1 row, 3 columns. Proper row vector.

Deep learning code mein rank-1 array (m,) se bachna achha hota hai. Ye kabhi row jaisa, kabhi column jaisa act karta hai. Isliye labels ko aksar Y.shape = (1, m) aur biases ko (n, 1) rakhte hain.

Dhyan rakhna: a.T rank-1 array pe kuch nahi badalta. np.array([1,2,3]).T ki shape phir bhi (3,) rahegi. Pehle reshape(3,1) karo.

Broadcasting — NumPy ka “copy mat banao, samajh lo” trick

Broadcasting ka matlab: chhoti cheez ko mentally repeat karke badi table se operation karna. Jaise class ke har student ko same notice milna.

OperationExampleResult
Matrix + row[[1,2,3],[10,20,30]] + [100,200,300][[101,202,303],[110,220,330]]
Matrix + column[[1,2,3],[10,20,30]] + [[5],[50]][[6,7,8],[60,70,80]]
Matrix + number[[1,2],[3,4]] + 10[[11,12],[13,14]]
Broadcasting simple rule: dimensions right side se compare karo. Same number chalega, ya ek dimension 1 ho to repeat ho sakta hai.
  • (2,3) + (1,3) chalega: row 2 baar repeat hogi.
  • (2,3) + (2,1) chalega: column 3 baar repeat hoga.
  • (2,3) + (2,2) error: 3 aur 2 match nahi, aur koi 1 bhi nahi.

axis=0 / axis=1 — kis direction mein jodna?

Axis ko lift/elevator ki tarah socho. axis=0 rows ke through neeche jaata hai, isliye har column ka total. axis=1 columns ke through side mein jaata hai, isliye har row ka total.

A = [[1,2,3],[10,20,30]]ShapeOutput
A.sum(axis=0)(3,)[11, 22, 33]
A.sum(axis=1)(2,)[6, 60]
A.sum(axis=1, keepdims=True)(2,1)[[6],[60]]

keepdims=True shape ko proper 2D rakhta hai. Backprop mein ye chhota option bahut shape bugs bachata hai.

Image ko vector banana

Computer photo ko pixels ki dabbi samajhta hai. 32 × 32 photo, 3 colour channels (R,G,B): total numbers = 32 × 32 × 3 = 3072.

Image
(32,32,3)→Flatten→Vector
(3072,1)
import numpy as np

img = np.zeros((32, 32, 3))
x = img.reshape(32 * 32 * 3, 1)  # (3072, 1)
assert x.shape == (3072, 1)

Transpose aur assert — shape police

Transpose table ko palat deta hai: (2,3) se (3,2). Matrix multiply mein yahi kaam aata hai: X @ W tabhi chalega jab beech ke dimensions match karein.

X = np.array([[1, 2, 3],
              [4, 5, 6]])        # shape (2, 3)
print(X.T.shape)                 # (3, 2)

w = np.array([[0.1], [0.2], [0.3]])
z = X @ w                        # (2, 3) @ (3, 1) = (2, 1)
assert z.shape == (2, 1)

Deep learning mein ye kahan milega?

DL Course 1 ke vectorization aur logistic regression labs mein, Course 1 ke photo flattening wale pages mein, aur har backprop formula mein. Bias b ko columns mein broadcast karna roz ka kaam hai.

Yaad rakhna: Shape pehle dekho, formula baad mein. Rank-1 (m,) se bachna, keepdims=True aur assert tumhare dost hain.

Dimaag mein aaye sawaal

Broadcasting actual copy banata hai kya?

Nahi, NumPy usually memory mein copy nahi banata. Woh bas operation karte waqt chhoti cheez ko repeat jaisa treat karta hai. Isi liye fast bhi hota hai.

axis yaad kaise rakhu?

axis=0 ko “rows hatao” samjho: answer mein rows wali dimension gayi. (2,3) se (3,). axis=1 mein columns wali dimension gayi: (2,).

Har jagah 2D array hi use karun?

Deep learning ke beginner code mein haan, mostly safer. Proper row/column shape likhne se formulas aur asserts dono clear rehte hain.

(4,1) + (1,3) ka result shape?

Column 3 baar repeat, row 4 baar repeat. Result shape (4,3).

A shape (5,10). A.sum(axis=0, keepdims=True) ka shape?

Rows collapse hui, par keepdims ne row dimension rakhi. Shape (1,10).

28 × 28 grayscale image ko column vector banao. Length?

Grayscale mein 1 channel hota hai. 28 × 28 × 1 = 784. Shape (784,1).
