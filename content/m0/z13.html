Moving average ka naam stock market jaisa lag raha hai.

Naam fancy hai, kaam simple: shor wale numbers ko smooth banana. Jaise roz ka mood up-down hota hai, par week ka mood trend zyada useful hota hai.

Normal average bhi to trend batata hai?

Haan, par normal average purani baaton ko bhi barabar weight deta hai. Moving average recent cheezon ko zyada importance deta hai.

Normal average vs moving average

Socho chai ki dukaan pe daily cups bike: [10, 12, 11, 30, 13]. Din 4 pe 30 ek spike hai — shaayad baarish thi. Hume smooth line chahiye jo har spike pe panic na kare.

Normal averageSab din equal. Din 4 tak average = (10 + 12 + 11 + 30) ÷ 4 = 15.75. Purana aur naya same weight.
Moving averageRecent din zyada matter. Purane din ka effect dheere-dheere kam hota hai. Optimizers isi smooth direction pe chalte hain.

Exponentially weighted average ka formula

vₜ = β vₜ₋₁ + (1 − β) θₜ
  • θₜ = aaj ka asli number, jaise aaj ka temperature ya gradient.
  • vₜ = smooth average jo hum maintain kar rahe hain.
  • β = purani memory kitni rakhein. 0.9 matlab 90% purana, 10% naya.

Shuru mein v₀ = 0, aur har naye din ka θ us din ka input hai. β = 0.9 lete hain: naya din average ko 10% apni taraf kheenchta hai, purani memory ka 90% bachta hai.

β se kitne “din” ka average?

Rough rule: moving average lagbhag 1 ÷ (1 − β) recent steps ko yaad rakhta hai.

βApprox memoryFeel
0.51 ÷ 0.5 = 2 stepsJaldi react, zyada shaky
0.91 ÷ 0.1 = 10 stepsCommon smooth setting
0.981 ÷ 0.02 = 50 stepsBahut smooth, dheere react

Bias correction — shuru ke values chhote kyu?

Table mein raw v din 1 pe sirf 1 aaya, jabki us din ka input 10 tha. Kyun? Kyunki hum v₀ = 0 se start kar rahe hain, zero average ko neeche kheenchta hai. Bias correction vₜ ÷ (1 − βᵗ) se shuru ka pull theek karta hai; yahan t update number hai, aur βᵗ ka matlab β ko t baar multiply karna.

beta = 0.9
v = 0                         # smooth memory yahin rakhenge
for t, theta in enumerate([10, 12, 11, 30, 13], start=1):
    v = beta * v + (1 - beta) * theta
    v_corrected = v / (1 - beta**t)  # zero-start ka correction
    print(round(v, 3), round(v_corrected, 3))

Deep learning mein ye kahan milega?

DL Course 2 ke Momentum, RMSprop, Adam, aur Batch Normalization pages mein. Momentum gradients ka moving average rakhta hai. RMSprop squared gradients ka. Adam dono ko bias correction ke saath milata hai.

Dhyan rakhna: β ko learning rate mat samajhna. β memory control karta hai; learning rate α update ka step size control karta hai. Dono alag knobs hain.
Yaad rakhna: Moving average = naya number thoda, purani smooth memory zyada. Bias correction shuru ke zero-start ko fix karta hai.

Dimaag mein aaye sawaal

β bada karne se line better hoti hai?

Always nahi. β bada = smoother, par late reaction. Agar data jaldi badal raha hai to β bahut bada model ko slow bana sakta hai.

Exponential naam kyu?

Purane values ka weight β, β², β³ jaise powers se ghat-ta hai. Isliye old memory exponentially fade hoti hai.

Bias correction hamesha use karna padta hai?

Adam mein haan, standard formula ka part hai. Simple plotting/smoothing mein kabhi ignore bhi kar dete hain, kyunki kuch steps baad effect chhota ho jaata hai.
