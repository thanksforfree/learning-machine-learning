YOLO boxes de raha hai. Phir region proposals aur U-Net kyun?

Box kabhi enough hota hai, kabhi nahi. “Car yahan hai” traffic camera ke liye okay. Par doctor ko tumor ka exact shape chahiye, sirf rectangle nahi.

Matlab har pixel ka label?

Haan. Ye semantic segmentation hai. Photo ke har pixel ko bolna: road, car, sky, tumor, background… full rangoli bharni padti hai.

Region proposals: pehle possible areas suggest karo

YOLO ek-shot style hai. Region proposal family thoda alag sochti hai: pehle image mein kuch “interesting regions” propose karo, phir un regions ko classify/refine karo.

R-CNNRegion proposals nikalo, har crop ko CNN se classify karo. Accurate, par slow.
Fast R-CNNPoori image ka feature map ek baar banao, proposals ko us map se classify karo. Reuse zyada.
Faster R-CNNProposal banana bhi neural network se. Region Proposal Network image ke andar candidate boxes suggest karta hai.

Simple analogy: kirana shop mein pehle shelf pe suspicious packets shortlist karo, phir har packet ka bill detail se check karo. Har item ko zero se scan nahi.

Semantic segmentation: har pixel ki class

Detection output boxes hai. Segmentation output image ke same height-width ka label map hai. Agar input 256×256 hai aur 4 classes hain, output shape 256×256×4 ho sakta hai — har pixel ke liye 4 class scores.

Transpose convolution: chhoti map ko bada banana

CNN downsampling se feature map chhota hota gaya. Segmentation mein output ko wapas image size tak bada banana hai. Transpose convolution ek learnable upsampling layer hai.

Shape formula ka simple version:

output = (n − 1) × s + f − 2p
  • n = input size
  • s = stride
  • f = filter size
  • p = padding

Example: input size 5, stride 3, filter 4, padding 1:

TermValue
(n − 1) × s(5 − 1) × 3 = 12
+ f12 + 4 = 16
− 2p16 − 2 = 14

Ek easy no-overlap picture: 2×3 input aur 2×2 all-ones kernel, stride 2. Har input number apna 2×2 block paint karta hai.

U-Net: neeche jao, phir upar aao

U-Net ka shape “U” jaisa hai. Left side encoder: image chhoti hoti jaati hai, channels badhte jaate hain. Right side decoder: feature map bada hota jaata hai, segmentation map banne lagta hai.

Input image→Downsample
context→bottleneck→Upsample
detail wapas→h×w×classes

Skip connections U-Net ka dil hain. Encoder ke early layers mein fine edges aur location detail hoti hai. Decoder ko jab output sharp banana hota hai, woh same level ke encoder features se shortcut le leta hai. Jaise rangoli banate waqt pehle outline save kar li, phir color bharte waqt outline dobara dekh li.

# U-Net block ka rough idea
c1 = conv_block(inputs)
p1 = max_pool(c1)
c2 = conv_block(p1)
u1 = transpose_conv(c2)          # size bada karo
u1 = concatenate([u1, c1])       # skip: old detail jodo
out = conv_1x1(u1, classes)      # har pixel ke class scores

Output: h × w × classes

Agar input 128×128 road image hai aur classes hain road, vehicle, person, background — output 128×128×4. Har pixel pe softmax chalta hai. Pixel (20,50) pe [0.05, 0.80, 0.10, 0.05] mila to woh vehicle pixel hai.

Dhyan rakhna: Segmentation label image ko resize karte waqt normal blur interpolation mat laga dena. Labels class IDs hain, colors nahi. Nearest-neighbor resize use karo, warna 1 aur 2 ka mix 1.4 jaisa weird label ban sakta hai.
Yaad rakhna: Detection box deta hai; segmentation har pixel ka label deti hai. U-Net downsampled context aur skipped fine detail ko jodke sharp masks banata hai.

Dimaag mein aaye sawaal

Semantic aur instance segmentation mein farak?

Semantic segmentation bolta hai “ye sab car pixels hain.” Instance segmentation alag-alag cars ko separate IDs bhi deta hai: car 1, car 2, car 3.

Transpose convolution normal resize se better hai?

Resize fixed rule hai. Transpose convolution weights seekhta hai, to task ke hisaab se upsampling kar sakta hai. Kabhi dono combine bhi hote hain.

U-Net medical images mein popular kyu?

Medical datasets aksar chhote hote hain, aur exact boundary important hoti hai. U-Net skip connections se detail bachata hai, isliye masks sharp milte hain.

Input size n=6, stride s=2, filter f=4, padding p=1. Transpose conv output size?

(6−1)×2 + 4 − 2×1 = 10 + 4 − 2 = 12.

256×256 image, 6 classes. Segmentation output shape?

Har pixel ke liye 6 class scores, so 256×256×6.

U-Net skip connection ka short reason?

Decoder ko exact location/edge detail wapas milti hai. Sirf bottleneck se output blurry ho sakta hai.
