Localization ek object ke liye theek hai. Par road photo mein cars alag-alag jagah hongi. Model ko kahan-kahan dekhna chahiye?

Sabse seedha jugaad: ek chhoti khidki lo, image pe ghumaao, har jagah classifier chalao. Jaise security guard torch leke parking lot scan karta hai.

Sounds simple. Problem?

Torch wali walking bahut slow ho sakti hai. Isi liye sliding windows ka convolutional version aaya — same kaam, par repeated calculation bachake.

Pehle ek cropped classifier train karo

Shuru mein classifier ko clean training examples do: tightly cropped car images aur non-car images. Matlab photo ka center mostly object ho. Ye model bolega: “is 20×20 ya 72×72 patch mein car hai ya nahi.”

Positive cropCar frame ke andar fit. Label = 1.
Negative cropRoad, tree, wall, sky. Label = 0.

Ab classifier trained hai. Lekin real image mein crop ready nahi milta. To window ko image pe slide karte hain.

Sliding window: khidki ghumaao, classifier chalao

Computation jaldi badh jaata hai. Example: 90×90 image, 30×30 window, stride 10. Ek direction mein positions = ⌊(90−30)/10⌋+1 = 7. Total positions = 7×7 = 49. Agar 3 window sizes try kar rahe ho, 147 classifier runs.

FC layer ko convolution mein badalna

Old-style CNN classifier ke end mein fully connected layer hoti thi. Par agar previous activation 6×6×12 hai aur FC layer 96 units ki hai, to use 6×6 convolution with 96 filters ki tarah likh sakte ho.

6×6×12 input patch → 1×1×96 output
  • FC view = 6×6×12 = 432 numbers flatten, phir 96 units
  • Conv view = 6×6 filter poore 6×6 area pe baithta hai, output 1×1×96
  • Dono ka math same, bas conv view large image pe repeat work share kar leta hai.

Ye chhota sa rewrite important hai. Classifier ab kisi fixed crop pe hi nahi, larger image pe bhi convolution ki tarah chal sakta hai.

Ek hi pass mein saari windows

Maan lo toy classifier 20×20×3 crop pe final output 1×1×5 deta hai: pehle 5×5 stride-2 conv se 8×8 banta hai, phir 8×8 conv se 1×1. Agar tum 26×26×3 image doge, pehli layer 11×11 banayegi, aur final output 4×4×5 hoga. Ye 4×4 grid = solah sliding-window predictions, ek single forward pass mein.

Repeated crop→Same conv calculations baar-baar→Convolutional sliding window→Calculations share

Intuition: overlapping windows mein image ka zyada hissa common hota hai. Normal sliding window us common part ka feature baar-baar nikalta hai. Conv version ek baar feature map bana ke sab locations ka result nikal deta hai.

Par box exact nahi hota

Weakness bhi samjho. Window ka size aur stride fixed hai. Agar car thodi beech mein hai, model sirf nearest grid/window location dega. Box “lagbhag” sahi ho sakta hai, par tight nahi.

Dhyan rakhna: Stride chhota karoge to location better hogi, par computation badhega. Stride bada karoge to fast, par object miss ya loose box ka chance badhega.

Is idea ne YOLO ka raasta banaya

Sliding windows bolta hai: “har jagah classifier chalao.” YOLO bolta hai: “ek hi network poori image dekhe, grid ke har cell ke liye box aur class predict kare.” Dono mein convolutional sharing wali soch common hai.

# Rough shape thinking
image = (16, 16, 3)
conv_classifier_output = (2, 2, 4)  # 4 grid locations, 4 class scores
# crop-by-crop chalate to 4 forward passes lagte
Yaad rakhna: Sliding windows simple hai par slow; FC ko conv mein badalke overlapping windows ke predictions ek forward pass mein mil sakte hain.

Dimaag mein aaye sawaal

Window sizes multiple kyu?

Object kabhi paas hoga, kabhi door. Paas wali car badi dikhegi, door wali chhoti. Different window sizes scales ko cover karte hain.

FC ko conv banana sirf trick hai ya weights change hote hain?

Weights ka meaning same rehta hai. Bas matrix multiply ko convolution ke form mein reshape kar dete hain, taaki wahi operation spatial locations pe repeat ho sake.

Convolutional sliding windows perfect detection hai?

Nahi. Fast hai, par box location grid/stride se bandhi hai. YOLO jaise methods box coordinates directly predict karke is weakness ko improve karte hain.

128×128 image, 32×32 window, stride 16. Ek scale pe kitni window positions?

Ek direction mein ⌊(128−32)/16⌋+1 = 6+1 = 7. Total 7×7 = 49 windows.

6×6×12 activation ko 1×1×96 banane ke liye conv filter shape kya hoga?

Filter spatial size 6×6, depth 12, number of filters 96. Shape 6×6×12×96.

Stride bahut bada rakhne ka risk?

Object do window positions ke beech reh sakta hai. Model usko miss kar sakta hai ya loose box de sakta hai.
