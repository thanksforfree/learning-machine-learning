Classifier bolta hai “car hai”. Par self-driving car ko to yeh bhi chahiye ki car kahan hai, na?

Bilkul. “Kitchen mein chai hai” useful hai, par cup table ke kis kone pe hai ye bhi chahiye. Computer vision mein isko localization bolte hain.

To model ek label ke saath rectangle bhi dega?

Haan. Pehle “object hai ya nahi”, phir box ka center aur size, phir class. Ek hi output vector mein sab aa sakta hai.

Classification + localization

Normal classification mein answer hota hai: “ye photo ambulance hai.” Localization mein answer thoda richer hota hai: “ambulance hai, aur box yahan se yahan tak hai.” Traffic camera, warehouse robot, medical scan — sab jagah “kya” ke saath “kahan” bhi chahiye.

Output vector: ek dabbe mein saari baat

Maan lo 3 classes hain: pedestrian, car, bike. Output vector aisa rakh sakte hain:

y = [p_c, b_x, b_y, b_h, b_w, c₁, c₂, c₃]
  • p_c = object present? 1 matlab haan, 0 matlab nahi
  • b_x, b_y = box center ka x,y position (aksar image ke width/height se normalized)
  • b_h, b_w = box height aur width
  • c₁,c₂,c₃ = class one-hot, jaise car ke liye [0,1,0]

Example: 200×100 image mein box left=50, top=20, right=150, bottom=70 hai. Center x=(50+150)/2=100, center y=(20+70)/2=45. Normalize karo:

QuantityCalculationValue
bₓ100 ÷ 2000.50
bᵧ45 ÷ 1000.45
b_w(150 − 50) ÷ 2000.50
bₕ(70 − 20) ÷ 1000.50

Agar class car hai, target vector banega: [1, 0.50, 0.45, 0.50, 0.50, 0, 1, 0]. Notice karo: order fixed hai. bₕ aur b_w ko ulta kar diya to model ki duniya hil jayegi.

Loss: jab object hi nahi, box ka homework mat check karo

Agar photo mein koi object nahi hai, target p_c = 0. Tab bₓ, bᵧ, bₕ, b_w aur class labels ka matlab hi nahi. Loss sirf p_c pe lagao. Warna model ko random boxes ke liye saza milegi, jo unfair hai.

0.2² + 0.05² + 0.05² + 0.05² + 0.10² + 0.10² + 0.30² + 0.20² = 0.1975

Landmark detection: rectangle nahi, points

Kabhi box enough nahi hota. Face filter app ko aankhon ke corners, nose tip, mouth corners chahiye. Fitness app ko shoulder, elbow, wrist points chahiye. Isko landmark detection bolte hain.

Output vector mein har landmark ke x,y coordinates jod do: [eye_left_x, eye_left_y, eye_right_x, eye_right_y, ...]. Agar 68 face landmarks hain, to 136 coordinate numbers. Saath mein face present score bhi rakh sakte ho.

Dhyan rakhna: Labels har photo mein same order mein hone chahiye. Photo A mein point 1 left eye aur Photo B mein point 1 nose ho gaya, to model ko lagta hai teacher khud confused hai.

Labels banana boring hai, par wahi gold hai

Localization ke liye har training image mein box draw karna padta hai. Landmark detection ke liye same points mark karne padte hain. Ye data labeling ka kaam thoda shaadi ke invitation list jaisa hai — boring, par galti hui to baad mein bahut phone aate hain.

# target vector banane ka simple idea
pc = 1
bx = (x1 + x2) / 2 / image_w
by = (y1 + y2) / 2 / image_h
bw = (x2 - x1) / image_w
bh = (y2 - y1) / image_h
y = [pc, bx, by, bh, bw, 0, 1, 0]  # class = car
Yaad rakhna: Localization classifier ka bada bhai hai: “object hai?” ke saath “box kahan hai?” aur “class kya hai?” ek vector mein predict karo.

Dimaag mein aaye sawaal

bₓ,bᵧ top-left corner kyu nahi rakhte?

Rakh sakte ho, par center + height/width object detection mein common aur convenient hai. Center se object ko grid cell assign karna bhi easy hota hai, jo YOLO mein kaam aayega.

Agar image mein do cars hain to?

Ye simple localization setup ek main object ke liye hai. Multiple objects ke liye detection algorithms chahiye, jahan grid cells, anchors ya proposals use hote hain.

Coordinates 0 se 1 ke beech kyu normalize karte hain?

Training stable hoti hai. 0.45 jaise numbers model ke liye 183 pixels se zyada friendly hote hain, aur different image sizes pe same idea chal sakta hai.

✍️ Ab tumhari baari (pehle khud socho, phir answer kholna)

300×200 image mein box left=60, top=50, right=210, bottom=150. bₓ,bᵧ,b_w,bₕ?

Center x=135, center y=100. bₓ=135/300=0.45, bᵧ=100/200=0.50, b_w=150/300=0.50, bₕ=100/200=0.50.

p_c = 0 wali image mein class loss include karna chahiye?

Nahi. Jab object hi nahi, class ka answer meaningful nahi. Sirf object-present score ko train karo.

5 landmarks predict karne hain. Sirf coordinates ke liye output size kitna?

Har landmark ke x aur y — 2 numbers. 5 × 2 = 10 coordinate outputs.
