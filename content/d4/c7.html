1×1 convolution sunke mujhe lagta hai ye kya mazaak hai. Ek pixel ka filter kya seekhega?

Spatially ek pixel dekhta hai, haan. Par depth mein poore channels dekhta hai. Agar input 32×32×128 hai, to 1×1 filter actually 1×1×128 hota hai.

To woh channels mix karta hai?

Bilkul. Jaise 128 chutney bottles mein se 40 useful mixes bana do. Height-width same, channels kam. Ye computation bachane ka zabardast trick hai.

Aur Inception?

Inception bolta hai: “3×3 chahiye ya 5×5? Pata nahi. Sab try karo, phir outputs jod do.” Smart part: pehle 1×1 bottleneck laga ke cost kam karo.

1×1 conv: channels ghatana, information mix karna

Input 32×32×128 hai. Agar 40 filters of size 1×1×128 lagaye, output 32×32×40 hoga. Spatial size same, depth 128 se 40.

32×32×128 --(40 filters of 1×1×128)--> 32×32×40
  • 1×1 spatial window hai
  • 128 depth poori previous channels ko dekhta hai
  • 40 filters = output ke 40 channels

Har pixel location pe ye chhota fully-connected layer jaisa kaam karta hai: 128 channel values ko 40 naye channel values mein mix karta hai.

Inception ka idea: sab filter sizes ek saath

Ek single layer mein kya choose karein — 1×1, 3×3, 5×5, ya pooling? Inception module kehta hai: sab branches chalao, phir channel dimension mein concatenate karo.

Computation cost: plain 5×5 vs bottleneck

Yahan asli maza aata hai. Input 32×32×128. Hume 40 filters of 5×5 chahiye.

ApproachMultiplicationsApprox
Direct 5×5 conv32×32×128×5×5×40131,072,000 ≈ 13.11 crore
1×1 reduce to 24 channels32×32×128×243,145,728
Then 5×5 conv to 4032×32×24×5×5×4024,576,000
Bottleneck total3,145,728 + 24,576,00027,721,728 ≈ 2.77 crore

Same style ka 5×5 feature, par cost lagbhag 4.7x kam. 1×1 bottleneck ne 128 channels ko pehle 24 mein compress kar diya.

Inception module aur side branches

Full Inception network aise modules stack karta hai. Kuch versions mein beech se side classifiers nikle the — chhoti auxiliary branches. Unka kaam tha training ke dauraan signal ko deeper layers tak help dena. Final prediction main branch se hoti hai.

Module ka benefit: network khud decide kar sakta hai ki kis layer pe small detail important hai ya bigger 5×5 context. Hum manually single filter size pe shaadi fix nahi kar rahe.

Naam ka filmi kissa

“Inception” naam thoda movie-inspired joke bhi tha: network ke andar network jaisa module. Matlab ek layer ke andar parallel mini-network branches. Naam yaad reh jaata hai, par concept yaad rakho: multi-scale filters + 1×1 bottlenecks.

# Inception-style branch idea
branch5 = Conv2D(24, 1, activation="relu")(x)  # bottleneck
branch5 = Conv2D(40, 5, padding="same", activation="relu")(branch5)
branch3 = Conv2D(40, 3, padding="same", activation="relu")(x)
out = concatenate([branch3, branch5], axis=-1)
Dhyan rakhna: 1×1 conv spatial size nahi badalta-ghatata, jab tak stride 1 ho. Uska main kaam channels mix/resize karna hai.
Yaad rakhna: Inception ka dil hai “parallel choices”, aur uska budget manager hai “1×1 bottleneck”.

Dimaag mein aaye sawaal

1×1 conv non-linearity bhi de sakta hai?

Haan. 1×1 conv ke baad ReLU lagao, to har pixel location pe channels ka non-linear mix ban jaata hai.

Concatenate aur add mein farak?

Inception branches ko channels mein concatenate karta hai, depth badh jaati hai. ResNet shortcut usually add karta hai, shape same chahiye.

5×5 filter expensive kyu?

3×3 mein 9 spatial weights, 5×5 mein 25. Channels aur filters ke saath multiply hote hi cost bada jump leti hai.
