Error analysis — galtiyon ko khud dekho

Spam filter ne CV set mein 100 emails galat classify kiye. Unko haath se padho aur category banao:

Galti ki categoryGintiFaisla
Loan / finance wale spam40Yahan mehnat karo — sabse bada fayda
Phishing links wale25Ye bhi important
Sirf image wale spam5Baad mein
Jaan-boojh ke spelling galat3Abhi ignore — max 3% fayda

Ek email kai categories mein aa sakta hai, no issue. Faayda ye hai ki tumhara time guesswork mein nahi jalta — seedha dikhta hai kahan mehnat ka fayda sabse zyada hai.

Data badhane ke smart tareeke

Targeted dataSab kuch nahi — bas us category ka zyada data laao jahan galti ho rahi (jaise finance spam).
Data augmentationPurane example ko thoda badal ke naya banao: letter “A” ki photo ko ghumao, thoda tedha karo; awaaz mein background shor milao. Label wahi rehta hai.
Synthetic dataComputer se nakli par realistic data banao, jaise alag-alag fonts se text ki photos.
Data-centric sochKabhi model badalne se zyada fayda data sudharne se hota hai (galat labels theek karna).
Augmentation mein dhyan: Wahi badlav karo jo asli duniya mein aata hai. Awaaz ko ulta chalana ya bilkul random pixel shor daalna aam taur pe madad nahi karta.

Transfer learning — kisi aur ki mehnat ka fayda

Mere paas sirf 1000 photos hain. Chalega?

Kisi ne already 10 lakh photos pe ek bada network train kiya hai (billi, car, ped sab). Uski pehli layers edges, shapes pehchanna seekh chuki hain — ye har photo problem mein kaam aata hai. Tum bas aakhri layer apne kaam ke liye badlo aur apni 1000 photos pe fine-tune karo. Jaise gaadi chalana seekha hua insaan truck jaldi seekh leta hai.

Option 1 (kam data)Purani layers freeze, sirf nayi output layer train karo.
Option 2 (thoda zyada data)Saari layers train karo, par pre-trained weights se shuru karke.

Shart: input same type ka ho (photo ke liye photo wala model, awaaz ke liye awaaz wala).

Deployment aur zimmedari

Deploy: model ek server pe chalta hai, app usse request bhejta hai (“is photo mein kya hai?”) aur jawab leta hai. Kaam yahin khatam nahi. Phir monitor karna padta hai — duniya badalti hai, data badalta hai, model purana ho jaata hai. Isko MLOps kehte hain.

Fairness aur ethics: model kisi group ke saath galat bhedbhaav (jaise loan approval mein) kar sakta hai, ya galat use ho sakta hai. Launch se pehle: alag-alag groups pe performance check karo, possible nuksaan ki list banao, aur kuch galat hua to kya karoge (rollback plan) — pehle se tay karo.

Error analysis ka ROI calculate karo

Galtiyan dekhna boring lagta hai. Direct bigger model try karun?

Bigger model try kar sakte ho, par pehle 100 galtiyan dekhna detective work hai. Wahi batata hai ki mehnat kahan lagani hai. Warna tum wrong problem solve kar sakte ho.

Maan lo CV set mein 200 errors hain. Tumne 100 random errors inspect kiye:

Dimaag mein aaye sawaal

100 galtiyan haath se dekhna time waste nahi?

Ulta! Ek-do ghante ka error analysis mahino ki galat mehnat bacha sakta hai. Galtiyan zyada ho to random 100–200 sample dekho.

Transfer learning mein kaunsa model lun?

Jo tumhare jaise input pe train hua ho aur publicly available ho. Photo problem hai to image model, text problem hai to text model. Aajkal images, text, audio sab ke liye pre-trained models milte hain.

Kitni galtiyan inspect karni chahiye?

Start mein 50–100 ka random sample kaafi signal de deta hai. Agar categories unclear hain, 200 tak jao. Poora dataset manually dekhna zaroori nahi.

Data-centric ka matlab model badalna mana hai?

Nahi. Matlab model ke saath-saath data quality, labels, coverage aur distribution ko equal importance do. Kabhi-kabhi 1 ghanta label cleaning 1 hafte ke model tuning se better hota hai.
