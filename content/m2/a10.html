Mere model ki accuracy 90% hai. Party?

Party se pehle ek sawaal. Maan lo 100 patients mein sirf 10 bimaar hain. Ek “bewakoof model” jo hamesha bole “sab healthy hain” — uski accuracy bhi 90% hai! Par usne ek bhi bimaar nahi pakda. Jab positive cases rare hon (bimaari, fraud), accuracy dhokha de sakti hai.

Example: 100 patients, 10 sach mein bimaar. Model ne 8 ko bimaar bola, jinme 6 sach mein bimaar the.

Sach mein bimaarSach mein healthy
Model: bimaar6 (True Positive)2 (False Positive)
Model: healthy4 (False Negative)88 (True Negative)

Is table ko confusion matrix kehte hain.

Precision = 6 / 8 = 75%“Model ne jinko bimaar bola, unme se kitne sach mein bimaar the?” — model ki baat pe kitna bharosa.
Recall = 6 / 10 = 60%“Jitne sach mein bimaar the, unme se kitne pakde?” — kitne miss nahi hue.

“Hamesha healthy” wale model ka recall = 0 / 10 = 0%. Bas, hero ki pol khul gayi.

Dono mein kheenchataani (trade-off)

Threshold badhao: sirf 90% pakka ho tab “bimaar” bolo. Precision upar, recall neeche — kam galat alarm, par kuch cases miss. Threshold ghatao: 30% pe bhi bolo. Recall upar, precision neeche. Sahi threshold problem pe depend karta hai: gambhir bimaari mein miss karna zyada bura, to recall pe dhyan.

F1 = 2 × P × R / (P + R) = 2 × 0.75 × 0.6 / 1.35 = 0.67
  • Ek number jo dono ko combine kare. Simple average se farak: agar ek bhi bahut kam ho to F1 bhi kam aata hai. (P = 1, R = 0 → average 0.5 dikhta, par F1 = 0.)

Threshold badalne ka live effect

Precision-recall trade-off sun liya, par threshold ghumaane se numbers kaise hilte hain?

Chalo same 10 bimaar patients wale example mein teen thresholds try karte hain. High threshold strict teacher jaisa, low threshold cautious doctor jaisa.

Maan lo 100 patients mein 10 sach mein bimaar hain. Model probability deta hai; threshold se decide hota hai “bimaar” kab bolna.

ThresholdTPFPFNPrecisionRecallFeel
0.805155/6 = 83%5/10 = 50%Kam alarm, zyada miss
0.508428/12 = 67%8/10 = 80%Balanced
0.301010010/20 = 50%10/10 = 100%Sab pakde, alarms zyada

Medical screening mein 0.30 acceptable ho sakta hai kyunki miss nahi chahiye. Spam filter mein 0.80 better ho sakta hai kyunki genuine email spam mein jaana painful hai.

F1(threshold 0.50) = 2 × 0.67 × 0.80 / (0.67 + 0.80) ≈ 0.73
  • F1 tab useful hai jab precision aur recall dono ko balance karna ho.
Dhyan rakhna: Threshold test set pe tune mat karo. CV set pe threshold chuno, test pe final report do.

Accuracy rare cases mein kyu dhokha deti hai?

Ek aur numeric check: 1000 transactions mein 10 fraud. Model A sabko non-fraud bolta hai. Model B 8 fraud pakadta hai, par 20 false alarms deta hai.

ModelAccuracyRecallBusiness feel
A: sab safe990/1000 = 99%0/10 = 0%Fraud pakda hi nahi
B: alert model972/1000 = 97.2%8/10 = 80%Useful despite lower accuracy

Isliye rare positive problems mein “highest accuracy” winner nahi hota. Kaam ka metric choose karo.

Beginner checkpoint: Metric choose karne se pehle positive class define karo. Fraud detection mein “fraud” positive hai; spam filter mein “spam” positive ho sakta hai.
Yaad rakhna: Precision = “jo bola woh sahi tha?”, Recall = “jo tha woh pakda?”. Rare cases mein accuracy ki jagah ye dekho.

Dimaag mein aaye sawaal

Precision aur recall yaad kaise rakhun?

Precision = model ki baat ki quality (uske “haan” kitne sachche). Recall = yaaddasht — asli cases mein se kitne “yaad” (pakde).

Spam filter mein kya zyada important?

Precision — kyunki boss ki urgent email galti se spam mein chali gayi to din kharab. Isliye spam filter threshold thoda upar rakhta hai, taaki false positives kam hon.

False positive aur false negative yaad kaise rakhu?

False positive = model ne “haan” bola par sach mein na. False negative = model ne “na” bola par sach mein haan. Pehla galat alarm, doosra miss.

F1 kab use nahi karna chahiye?

Jab precision aur recall ki cost equal nahi ho. Bimaari screening mein recall much more important ho sakta hai; spam mein precision. Tab business/medical cost ke hisaab se metric choose karo.
