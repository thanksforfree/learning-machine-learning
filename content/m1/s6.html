Tumne scaling bola… ye kya hai?

Socho ek feature 300 se 2000 tak jaata hai (size) aur doosra 0 se 5 (bedrooms). Cost ki katori ab gol nahi rehti — ek taraf bahut lambi aur patli ho jaati hai, jaise lamba nala. Gradient descent usme deewaron se takraata zig-zag chalta hai, bahut slow.

To solution?

Dono features ko lagbhag same range mein le aao, jaise −1 se 1. Katori gol ho jaati hai aur gradient descent seedha neeche jaata hai. Ye bas unit badalne jaisa hai — cm ko meter mein likhna. Information wahi rehti hai.

Matlab scaling data ko cheat nahi karta?

Bilkul nahi. ₹100 ko “one hundred rupees” bolna ya “0.1 thousand rupees” bolna — paisa wahi hai. Bas model ko padhne mein aasani hoti hai.

Scaling ke teen tareeke (example: size = 1500)

Maan lo training data mein size ka max = 2000, min = 300, average (μ) = 1000, standard deviation (σ) = 400.

TareekaFormula1500 ka kya bana
Max se dividex ÷ max1500 ÷ 2000 = 0.75
Mean normalization(x − μ) ÷ (max − min)500 ÷ 1700 = 0.29
Z-score(x − μ) ÷ σ500 ÷ 400 = 1.25

σ ka simple matlab: data average se aam taur pe kitna door phaila hai. Z-score 1.25 = “ye ghar average se 1.25 ‘aam doori’ bada hai”.

Naye data pe same scaling

Maan lo training μ = 1000 aur σ = 400 tha. Ab naye ghar aaye:

Naya sizeZ-scoreModel ko kya dena hai
700(700 − 1000) ÷ 400 = −0.75Average se thoda chhota
1500(1500 − 1000) ÷ 400 = 1.25Average se bada

Yahin beginner wali common galti hoti hai: naye 2 gharon ka alag μ/σ nikaal diya. Nahi. Training wali measuring tape hi use karni hai.

Galti mat karna: Jo μ aur σ training data se nikaale, wahi naye ghar pe bhi lagao. Naye data ka alag average nikaloge to model ko ulta-seedha input milega.

Training theek chal rahi hai? Graph dekho

x-axis pe iterations (kitne steps), y-axis pe cost. Isko learning curve kehte hain.

Pro tip: Bahut chhote α pe cost har step thoda ghatna hi chahiye. Agar tab bhi badh raha hai, to code mein bug hai (jaise minus ki jagah plus likh diya).

Yaad rakhna: Scaling model ki information nahi badalti; bas gradient descent ko seedha, tez raasta dikha deti hai.

Dimaag mein aaye sawaal

Scaling se prediction badal jayega kya?

Model sahi train ho to nahi — bas training fast aur stable hoti hai. Bas yaad rakho: naye input ko bhi same tarike se scale karke model ko do.

Kab scaling karna zaroori hai?

Jab features ki range bahut alag ho (0–1 vs 0–10,000). Doubt ho to kar do — nuksaan nahi hota.

−1 se 1 hi kyu?

Strict rule nahi. −3 se 3, ya 0 se 1 bhi theek hai. Problem tab hai jab ek feature −100 se 100 aur doosra −0.001 se 0.001 ho.

Automatic “ruk jao” rule hota hai?

Hota hai: agar ek step mein cost bahut chhote number (jaise 0.001) se kam ghate to ruk jao. Par sahi number chunna mushkil hai, isliye graph dekhna zyada bharosemand hai.

Scaling ke baad units ka kya?

Model scaled numbers pe kaam karta hai, par final prediction waise hi lakh/price mein hoti hai. Tum input ko scale karte ho; output ko zaroori nahi, jab tak tumne target y ko bhi scale karne ka decision na liya ho.
