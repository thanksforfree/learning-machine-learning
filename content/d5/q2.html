Normal neural network ko sentence de dein na. “Aaj baarish hogi” ke 3 one-hot vectors chipka do.

Chhote sentence pe jugaad chalega. Par kal 3 words, parso 30 words? Aur “baarish” position 2 pe aaye ya position 8 pe, model ko same idea reuse karna chahiye.

Toh hume koi aisa network chahiye jo line-by-line padh sake?

Bilkul. RNN ek reader ki tarah hai: ek word padhta hai, apni chhoti si memory update karta hai, phir agla word.

Normal network kyu awkward ho jaata hai

Alag lengths
Review: “mast” = 1 word. Review: “delivery late thi par taste mast” = 6 words. Fixed input layer ko dono kaise doge?
Position sharing nahi
“Delhi” 1st word ho ya 10th, NER model ko place ka signal same tarah use karna chahiye. Normal dense network har position ke liye alag weights seekh sakta hai.

Recurrent Neural Network same weights ko har time step pe reuse karta hai. Isliye “word ka pattern” position se kam chipakta hai.

RNN ka memory update

Har step pe do cheezein milti hain: abhi ka input x⟨t⟩ aur pichhli memory a⟨t−1⟩. Dono milke nayi memory a⟨t⟩ banate hain.

a⟨t⟩ = g(Wₐₐ a⟨t−1⟩ + Wₐₓ x⟨t⟩ + bₐ) ŷ⟨t⟩ = g(Wᵧₐ a⟨t⟩ + bᵧ)
  • a⟨t⟩ = hidden state / memory at time t.
  • Wₐₐ = purani memory ko kaise use karna.
  • Wₐₓ = current input ko kaise use karna.
  • Wᵧₐ = memory se prediction kaise banana.

Chhoti notation: Wₐ[a, x]

Formula lamba lag raha hai? Dono inputs ko side-by-side chipka do: [a⟨t−1⟩, x⟨t⟩]. Phir ek combined matrix Wₐ se multiply karo.

a⟨t⟩ = g(Wₐ [a⟨t−1⟩, x⟨t⟩] + bₐ)
  • Ye wahi baat hai, bas notebook mein neat likhne ka tareeka.
  • Jaise dosa batter aur aloo masala alag bowls se aate hain, par tawa pe ek hi dish banti hai.

Agar 3 labels hain — jaise person, place, other — to softmax probabilities ka total 1 hota hai. Yahan pehla label 62.9% chance le raha hai.

Activations ka practical choice

RNN ke hidden update mein aksar tanh use hota hai, kyunki memory ko −1 se +1 ke beech rakhta hai. Kabhi ReLU bhi use hota hai. Output side problem pe depend karta hai:

  • Binary answer: sigmoid.
  • Many classes: softmax.
  • Number predict karna: linear output.

Kamzori: RNN sirf pichhla context dekhta hai

Left-to-right RNN jab word 10 pe prediction karta hai, tab usne word 1 se 10 tak dekha hai. Future word 11, 12 nahi. NER mein kabhi future useful hota hai: “Java coffee pi” vs “Java class likhi”. Isliye aage bidirectional RNN aayega.

import numpy as np

def rnn_step(x_t, a_prev, Waa, Wax, ba):
    z = Waa @ a_prev + Wax @ x_t + ba
    a_t = np.tanh(z)      # chhoti memory update
    return a_t
Dhyan rakhna: RNN cell ki copies alag-alag layers nahi hain. Diagram mein 10 boxes dikhte hain, par weights same share hote hain.
Yaad rakhna: RNN ek word padhta hai, memory update karta hai, phir next word. Same weights har position pe reuse hote hain.

Dimaag mein aaye sawaal

a⟨0⟩ kya hota hai?

Usually zeros se start karte hain. Matlab model sentence shuru hone se pehle blank memory se baithta hai.

Har time step pe output zaroor chahiye?

Nahi. NER mein har word pe label chahiye. Sentiment mein sirf end pe ek output chahiye. Shape problem ke hisaab se badalta hai.

RNN long sentence yaad rakhta hai?

Thoda rakhta hai, par bahut lambi dependency mein struggle karta hai. GRU/LSTM isi dard ki medicine hain.

✍️ Ab tumhari baari (pehle khud socho, phir answer kholna)

Agar hidden state size 5 hai, toh a⟨t⟩ mein kitne numbers honge?

Hidden state size hi memory length hai. Isliye 5 numbers.

Softmax output [0.2, 0.5, 0.3] mein model ka chosen class kaunsa?

Sabse bada chance 0.5 hai, jo 2nd class ka hai. Class 2.

Same word different positions pe aaye, RNN kaunsa benefit deta hai?

Same weights reuse hote hain, isliye model pattern ko position-independent tarike se zyada easily seekh sakta hai.
