Forward pass samajh aa gaya. Par RNN train kaise hota hai?

Jaise tum puri cricket innings dekh ke bolte ho “yahan shot galat tha, yahan run lena tha”. RNN bhi end mein loss dekh ke purane time steps tak blame bhejta hai.

Time mein peeche blame? Thoda sci-fi lag raha hai.

Naam hi stylish hai: Backpropagation Through Time. Par idea wahi old backprop hai, bas unrolled RNN ke boxes ke across.

Har time step pe loss, total loss sum

NER jaise task mein har word ka label hota hai. Model har time step pe prediction ŷ⟨t⟩ deta hai. Har prediction ki chhoti loss L⟨t⟩, aur total loss in sab ka sum.

L = Σ L⟨t⟩ = L⟨1⟩ + L⟨2⟩ + ... + L⟨Tᵧ⟩
  • L⟨t⟩ = t-th output ki galti.
  • Total L = poori sequence ki galti.
  • Training ka goal: total L kam karna.

RNN shapes: problem ka design yahin se choose hota hai

Sequence model ka input length aur output length relation har app mein different hota hai. Ye table yaad ho gaya toh architecture choose karna kaafi easy ho jaata hai.

Many-to-many: Tₓ = Tᵧ

NER mein input “Aman Pune gaya” hai. Output bhi 3 labels: Person, Place, Other. Har input word ka ek label. Yahan har time step pe loss natural hai.

Many-to-one: sentiment

“Delivery late thi par biryani kamaal thi” — poora sentence padhne ke baad ek final answer chahiye: positive ya negative. Isliye RNN end tak memory banata hai, phir last state se output.

One-to-many: music banana

Ek seed note ya genre do: “lofi monsoon”. Model pehla note predict kare, phir us predicted note ko next input bana ke next note. Aise melody grow hoti hai.

Many-to-many alag lengths: translation

“Mujhe chai chahiye” ke 3 words hain, “I would like tea” ke 4 words. Yahan encoder input sentence ko summary mein pack karta hai, decoder output sentence banata hai. Tₓ aur Tᵧ match karna zaroori nahi.

loss = 0
for t in range(Ty):
    y_hat_t = outputs[t]
    loss += cross_entropy(y_hat_t, y_true[t])  # har step ka bill add
loss.backward()  # framework BPTT kar dega
Dhyan rakhna: Many-to-one mein har time step pe forced output mat lagao. Agar task ka answer sirf poori sequence ke baad milta hai, last hidden state se output lena simple aur clean hai.
Yaad rakhna: RNN ka loss time steps pe add hota hai, aur BPTT wahi loss ka blame time mein peeche bhejta hai.

Dimaag mein aaye sawaal

BPTT koi naya algorithm hai?

Core backprop hi hai. “Through time” isliye bolte hain kyunki RNN ko time steps mein unroll karke gradients pass hote hain.

One-to-one bhi sequence model hai?

Nahi, woh mostly normal network ka case hai. Table mein isliye rakha taaki contrast clear ho.

Translation mein encoder-decoder kyu?

Input aur output lengths alag hote hain. Encoder source sentence samajhta hai, decoder target sentence generate karta hai.
