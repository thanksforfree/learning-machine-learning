GRU gates samajh aa gaye. LSTM phir kyun famous hai?

LSTM thoda zyada detailed control deta hai: kya naya likhna, kya purana bhoolna, aur bahar kya dikhana. Jaise phone mein gallery, archive, aur screen brightness teen alag controls.

Teen gates, matlab teen switches?

Haan, soft switches. 0 se 1 ke beech. Aur isi wajah se LSTM long sequences mein kaafi reliable raha.

LSTM ke gates: update, forget, output

LSTM ka cell state c⟨t⟩ ek conveyor belt jaisa hai. Information relatively smooth tarike se aage ja sakti hai. Gates decide karte hain belt pe kya add, kya remove, kya output.

GateSymbolKaamEveryday feel
UpdateΓᵤNayi candidate memory kitni likhniNotebook mein naya point add?
ForgetΓfPurani memory kitni rakhniOld reminder delete?
OutputΓₒCell ka kitna hissa hidden output baneScreen pe kya dikhana?

Har gate Γ, current input x⟨t⟩ aur pichhle hidden state a⟨t−1⟩ se sigmoid ke through banta hai, isliye uski har value 0 aur 1 ke beech hoti hai. Cell ke har number ka apna soft switch hota hai; equations mein `*` element-wise multiplication hai.

Core equations

c̃⟨t⟩ = tanh(W_c [a⟨t−1⟩, x⟨t⟩] + b_c) c⟨t⟩ = Γᵤ * c̃⟨t⟩ + Γf * c⟨t−1⟩ a⟨t⟩ = Γₒ * tanh(c⟨t⟩)
  • c̃⟨t⟩ = candidate memory.
  • Γᵤ = candidate ko kitna add karna.
  • Γf = old cell ko kitna keep karna.
  • Γₒ = hidden output mein kitna reveal karna.
ValueNumber
Γᵤ, c̃0.7, 0.5
Γf, c old0.8, 0.4
c new0.7×0.5 + 0.8×0.4 = 0.67
Γₒ0.6
a new0.6×tanh(0.67) = 0.6×0.585 = 0.351

Peephole connection ka chhota zikr

Kuch LSTM versions gates ko cell state c bhi dekhne dete hain. Jaise gate bolta hai: “andar memory already kitni bhari hai, uske hisaab se open/close karun.” Isko peephole connection kehte hain. Basic idea same rehta hai; bas gate ko extra clue milta hai.

GRU ya LSTM — kab kya?

GRU
Thoda simpler, fewer gates, training fast ho sakti hai. Data chhota ho ya quick baseline chahiye, good choice.
LSTM
Zyada knobs, long dependencies pe historically strong. Jab sequence tough ho aur compute manageable ho, try karne layak.

Truth: pehle dono try karna normal hai. Koi universal winner nahi. Dataset, tuning, aur task matter karte hain.

Bidirectional RNN: dono disha ka context

NER mein “bank” ka meaning future word se clear ho sakta hai: “bank mein paisa” vs “river bank par”. Bidirectional RNN ek RNN left-to-right chalata hai, aur ek right-to-left. Har position pe dono memories combine.

prediction at t uses [a_forward⟨t⟩, a_backward⟨t⟩]
  • Forward memory past dekhti hai.
  • Backward memory future dekhti hai.
  • Limitation: poora sequence available hona chahiye. Live speech streaming mein future wait karna pad sakta hai.

Deep RNN: layers stack

Ek RNN layer low-level patterns pakad sakti hai, next layer higher pattern. Jaise first layer syllables/small phrases, second layer meaning chunks. RNNs ko stack kar sakte ho, par aam taur pe 2–3 layers kaafi hoti hain; bahut deep recurrent stack train karna heavy ho sakta hai.

x = inputs
for layer in rnn_layers:
    x = layer(x)          # har layer poori sequence return kare
logits = output_layer(x)  # task ke hisaab se last ya all steps
Dhyan rakhna: Bidirectional RNN ko future context chahiye. Agar tum real-time trigger word detect kar rahe ho, full future wait nahi kar sakte.
Yaad rakhna: LSTM cell state ko update, forget, output gates se control karta hai; BRNN future bhi dekhta hai; deep RNN layers stack karta hai.

Dimaag mein aaye sawaal

Forget gate 0 ho toh kya?

Old cell state ka woh hissa erase ho jaata hai. Γf 1 ke paas ho toh old info keep hoti hai.

LSTM mein hidden state aur cell state dono kyu?

Cell state long-term notebook hai. Hidden state current step ka visible summary hai jo output aur next computations mein jaata hai.

Deep RNN 10 layers kyu nahi?

Kar sakte ho, par recurrent training already heavy hai. Bahut layers gradients aur compute ko tough bana sakti hain. Practical start 2–3 se.

Streaming app mein BRNN ka issue kya hai?

BRNN future tokens bhi chahta hai. Live stream mein future abhi aaya nahi, isliye latency ya wait lagega.

Output gate ka kaam ek line mein?

Cell memory ka kitna hissa hidden output a⟨t⟩ mein dikhana hai, ye decide karta hai.
