Face encoding se rishta

Face recognition mein photo ko 128-number encoding mein convert karte ho. Same person ki photos paas, different person door. Word embeddings mein word ko vector banate ho. Similar meaning/usage wale words paas. Dono idea: raw object ko meaning-space ke point mein badalna.

Analogies: vector arithmetic ka magic-ish part

Classic style: e_man − e_woman ≈ e_king − e_queen. Matlab “gender direction” roughly consistent ho sakti hai. Practical analogy solve karte waqt: king − man + woman ≈ queen.

target ≈ e_king − e_man + e_woman
  • e_word = word ka embedding vector.
  • Nearest vector to target choose karte hain.
  • Ye perfect logic engine nahi; corpus bias aur noise affect karte hain.

Cosine similarity: direction compare karo

Embedding ka size kabhi word frequency se affect ho sakta hai. Cosine similarity direction compare karti hai: same direction close to 1, right angle 0, opposite −1.

cos(u, v) = (u · v) / (||u|| ||v||)
  • u · v = dot product.
  • ||u|| = vector length.
  • Cosine high = vectors same direction mein.

import numpy as np

def cosine(u, v):
    return np.dot(u, v) / (np.linalg.norm(u) * np.linalg.norm(v))

print(cosine(np.array([0.8, 0.6]), np.array([0.7, 0.7])))  # 0.99
Dhyan rakhna: Embedding dimensions ko human labels dekar over-interpret mat karo. “Dimension 17 = royalty” zaroori nahi. Useful geometry matters.
Yaad rakhna: Embeddings words ko dense meaning-space mein points banate hain; cosine se direction similarity naapte hain.

Dimaag mein aaye sawaal

Embeddings manually banate hain?

Nahi, usually training se learn hote hain. Hum dimension size choose karte hain, values model data se seekhta hai.

t-SNE plot mein distance exact hota hai?

Nahi. t-SNE visualization hai. Clusters dekhne ke liye useful, exact math ke liye original embeddings aur cosine use karo.

Analogies hamesha sahi hoti hain?

Nahi. Ye impressive pattern hai, guarantee nahi. Data bias, rare words, aur domain mismatch se answer weird ho sakta hai.

Vectors [1, 0] aur [0, 1] ka cosine kya hai?

Dot product 0, lengths 1 aur 1. Cosine = 0/(1×1) = 0.

Small sentiment dataset hai. Pretrained embeddings freeze karna kab sensible hai?

Jab data kam ho aur overfitting ka darr ho. Freeze karne se pretrained meaning safe rehta hai.
