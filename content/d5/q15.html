Single self-attention samajh aa gaya. Par “multi-head” kya extra karta hai?

Ek hi dost se advice loge to ek angle milega. Teen dost: ek grammar dekhega, ek meaning, ek long-distance relation. Multi-head attention bhi kai alag sawaal ek saath poochta hai.

Aur full Transformer block mein aur kya hota hai?

Attention ke baad feed-forward, residual, layer norm, decoder masking, output softmax — thoda kitchen set hai. Aaram se assemble karte hain.

Multi-head: kai alag “sawaal” ek saath

Single attention head ek type ka relation pakad sakta hai. Multi-head mein Q, K, V ko multiple learned projections se chhote spaces mein bhejte hain. Har head attention karta hai. Phir head outputs concatenate hote hain aur WO se mix hote hain.

headᵢ = Attention(QWᵢQ, KWᵢK, VWᵢV) MultiHead = Concat(head₁, head₂, ..., headₕ) WO
  • h = number of heads
  • Wᵢ = har head ki apni learned projection
  • WO = heads ko final vector mein mix karta hai

Encoder block: attention, feed-forward, repeat N baar

Transformer encoder block ka basic pattern: multi-head self-attention, phir position-wise feed-forward network. Dono ke around Add & Norm hota hai: residual connection plus layer normalization.

Input embeddings→Multi-head self-attention→Add & Norm→Feed-forward→Add & Norm

Residual ka matlab: layer output ke saath original input add karo. Jaise “agar new layer confused ho, purani info ka raasta khula rahe.” Layer norm activations ko stable scale pe rakhta hai. Ye training ko calm banata hai.

z = LayerNorm(x + Sublayer(x))
  • x = sublayer ka input
  • Sublayer = attention ya feed-forward
  • LayerNorm = vector ke features ko normalize karna

Ye block N baar stack hota hai. Lower layers local patterns pakad sakti hain; upper layers abstract meaning.

Decoder: future mat dekhna

Decoder training mein target sentence available hota hai, par model ko future word jhaankne nahi dena. Agar “I am eating” predict karte waqt model already “eating” dekh le, exam mein answer sheet khol di. Isliye masked self-attention use hota hai: position t sirf past aur current positions dekhe.

Decoder mein second attention bhi hota hai: encoder-decoder attention. Yahan Q decoder se aata hai, aur K, V encoder output se. Matlab decoder poochta hai, “mere next word ke liye source sentence ka kaunsa part useful hai?”

Positional encoding: order ka address

Self-attention set jaisa hai; agar position info na do to “dog bites man” aur “man bites dog” ka order blur ho sakta hai. Transformer embeddings mein positional encoding add karta hai. Classic version sine/cosine waves use karta hai, different frequencies ke saath.

PE(pos, 2i) = sin(pos / 100002i/d) PE(pos, 2i+1) = cos(pos / 100002i/d)
  • pos = token position
  • i = dimension pair index
  • d = model dimension
ExampleValue
pos = 2, i = 0: sin(2)0.909
pos = 2, i = 0: cos(2)−0.416
pos = 2, i = 1, d = 4: sin(2 / 100)0.020

Different frequencies se model nearby aur far positions dono ke patterns learn kar sakta hai. Aaj kal learned positional embeddings bhi popular hain, par reason same: order ka signal do.

Linear + softmax output

Decoder ka final vector vocabulary ke size ke logits mein map hota hai. Agar vocabulary 50,000 words ki hai, linear layer 50,000 scores degi. Softmax in scores ko probabilities banata hai. Training mein cross-entropy next correct token ko reward/punish karta hai.

# decoder hidden: [batch, d_model]
logits = hidden @ W_vocab + b_vocab   # [batch, vocab_size]
probs = softmax(logits)               # next-token probabilities, inference ke liye
loss = cross_entropy(logits, target)  # logits seedhe do; teacher forcing ke saath

Training mein masking do jagah

  • Padding mask: Batch mein sentences same length banane ke liye pad tokens add hote hain. Attention ko pad pe focus nahi karna chahiye.
  • Look-ahead mask: Decoder future target tokens ko nahi dekh sakta.
Dhyan rakhna: Mask sign galat hua to model ya to future dekh lega, ya useful tokens block kar dega. Training loss suspiciously low ya output bilkul bakwaas — dono mask bug ke symptoms ho sakte hain.

BERT, GPT kahan fit hote hain?

BERT mostly encoder-only Transformer family ka example hai. Woh bidirectional context se text understanding tasks mein strong raha: classification, question answering, embeddings. GPT decoder-only family ka example hai. Masked self-attention ke saath next token predict karta hai, isliye generation mein natural fit.

BERT-styleEncoder stack. Poora input context dekh ke representation banata hai.
GPT-styleDecoder stack. Past tokens dekh ke next token generate karta hai.
Specialization ka wrap-up, dost: Tumne linear models se start kiya, neural nets, CNNs, RNNs, embeddings, attention, aur ab Transformers tak aaye. Big picture ye hai: data ko useful representation mein badlo, loss se feedback lo, aur architecture ko problem ke shape ke hisaab se choose karo. Hype badalta rahega, par ye thinking tumhare saath rahegi.
Yaad rakhna: Transformer block attention se relations pakadta hai, feed-forward se features polish karta hai, residual/norm se training stable rakhta hai, aur masks se cheating rokta hai.

Dimaag mein aaye sawaal

Multi-head mein heads truly different cheezein seekhte hain?

Often haan, par manually assign nahi karte. Training decide karti hai. Kuch heads syntax, kuch position, kuch long-distance relation pakad sakte hain; kuch redundant bhi ho sakte hain.

Encoder-decoder Transformer kab use hota hai?

Translation, summarization, speech-to-text jaise tasks jahan input sequence aur output sequence dono alag roles mein hote hain. Encoder source padhta hai, decoder target generate karta hai.

Layer norm aur batch norm same hain?

Nahi. Layer norm ek example ke feature vector ke andar normalize karta hai, sequence models mein convenient hai. Batch norm batch statistics pe depend karta hai.

✍️ Ab tumhari baari (pehle khud socho, phir answer kholna)

4 heads hain, har head output dimension 8 hai. Concat dimension kya hoga?

4 × 8 = 32. Phir WO is 32-d vector ko desired model dimension mein project karega.

Decoder position 5 ko training mein kaunse positions dekhne chahiye?

Positions 1, 2, 3, 4, 5 allowed. Future 6, 7, ... blocked. Ye look-ahead mask karta hai.

BERT aur GPT ka simplest difference?

BERT-style encoder input ko samajhne ke liye poora context dekhta hai. GPT-style decoder past context se next token generate karta hai. Bas dost — ab tum sequence models ki poori kahani ka map dekh chuke ho.
