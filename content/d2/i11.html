Perfect analogy. Pehle road khaali thi to bada accelerator theek. Parking mein wahi speed rakhi to gaadi aage-peeche hoti rahegi.

To learning rate dheere-dheere kam?

Haan. Start mein bade kadam, end mein chhote kadam. Isko learning rate decay bolte hain.

Aur local minimum ka darr? Kahin galat gaddhe mein phas gaye to?

Deep learning mein asli villain aksar local minimum nahi, saddle point aur plateau hote hain. Ab woh bhi dekhenge.

Decay kyu: end mein finesse chahiye

Mini-batch training noisy hoti hai. Fixed α rakho to network optimum ke paas bhi thoda hilta rahega. Decay α ko time ke saath kam karta hai, taaki last mein model chhote, sambhal ke kadam le.

Ek common schedule: α = α₀ / (1 + decay_rate × epoch)

α = α₀ / (1 + decay_rate × epoch)
  • α₀ = starting learning rate
  • decay_rate = kitni speed se α ghatega
  • epoch = poore training data ka ek chakkar

Example: α₀ = 0.1, decay_rate = 0.05.

Local optima ka sach

2D graph mein local minimum easy dikhta hai: ek chhota gaddha jahan ball phas gayi. Par deep networks mein parameters lakhon-crores hote hain. High dimensions mein sab directions mein upar hona rare hai. Zyada common scene: kuch directions mein upar, kuch mein neeche — ghode ki saddle jaisa.

Saddle point pe slope zero ke paas lag sakta hai, to optimizer slow ho jaata hai. Par ek direction milte hi woh nikal sakta hai. Isliye “har problem local minimum hai” wala darr thoda purana ho chuka hai.

Plateaus: training slow kyu hoti hai

Plateau matlab zameen lagbhag flat. Gradient chhota, update chhota, progress slow. Momentum aur Adam yahan help kar sakte hain, kyunki woh recent directions ki memory rakhte hain. Learning rate decay end mein help karta hai, par plateau ke beech mein kabhi-kabhi α bahut chhota kar dena training ko aur slow kar sakta hai.

Practical flow: Pehle ek achha α find karo. Phir agar training end mein noisy settle ho rahi hai, decay add karo. Decay bad optimizer ya wrong α ka replacement nahi hai.
Dhyan rakhna: Decay ko start se bahut aggressive mat rakho. α jaldi chhota ho gaya to model parking spot tak pahunchne se pehle hi cycle ki speed pe aa jayega.
Yaad rakhna: Learning rate decay training ke end mein kadam chhote karta hai. Deep nets mein local minima se zyada saddle points aur plateaus training ko slow karte hain.

Dimaag mein aaye sawaal

Decay hamesha lagana chahiye?

Nahi. Pehle fixed α se baseline banao. Agar loss end mein bounce kar raha hai ya validation improve nahi ho raha, decay try karo.

Epoch aur iteration mein farak?

Iteration = ek mini-batch update. Epoch = poore training set ka ek full pass. Decay schedule dono ke basis pe ban sakta hai, par formula mein kya use ho raha hai clear rakho.

Plateau mein patience kitna?

Loss, dev metric aur learning rate teeno dekho. Kabhi bas wait karna padta hai, kabhi α adjust, kabhi architecture/normalization ki zaroorat hoti hai.
