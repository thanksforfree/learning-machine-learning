Tamatar ke daam pe smooth line

Raw sabzi price mein shor hota hai. Aaj baarish se supply late, kal mandi full. Par trend dekhna ho to smooth line chahiye. Har din ek naya daam θ_t aata hai, aur hum ek running value v_t update karte hain.

v_t = βv_{t−1} + (1 − β)θ_t
  • θ_t = aaj ka asli daam, jaise Rs. 38/kg
  • v_t = smooth daam jo hum rakhte hain
  • β = purani memory kitni rakho. 0 ke paas = jaldi bhoolo, 1 ke paas = dheere bhoolo
  • 1 − β = naye daam ka weight

Purane din ka wazan kaise ghat-ta hai

Aaj ka weight (1 − β). Kal ka β(1 − β). Parso ka β²(1 − β). Har step purana effect β se multiply hota jaata hai. Isliye naam mein “exponential” aata hai.

Code mein ek hi variable

Iska best part: saare purane daam store karne ki zaroorat nahi. Sirf v rakho, naya θ aate hi update karo.

beta = 0.9
v = 0
for theta in [28, 34, 30, 42, 38]:
    v = beta * v + (1 - beta) * theta
    print(v)   # smooth value update hoti rahegi
DL connection: Momentum gradients ka moving average rakhta hai. RMSprop squared gradients ka. Adam dono rakhta hai. Batch norm bhi mini-batch statistics ka moving average use karta hai.
Dhyan rakhna: β bada karna hamesha better nahi. β = 0.98 line ko bahut smooth karega, par agar mandi ka daam achanak badla to woh late samjhega. Optimizers mein bhi same trade-off.
Yaad rakhna: Naya signal thoda jodo, purani memory β se rakho. β jitna 1 ke paas, average utna smooth aur slow.

Dimaag mein aaye sawaal

Normal average aur moving average mein asli farak?

Normal average mein sab readings barabar. Moving average mein recent readings zyada important. Training mein recent gradients zyada kaam ke hote hain, isliye moving average useful hai.

Bias correction har baar lagana zaroori?

Nahi. Shuruaat mein v_0 = 0 ki wajah se value chhoti hoti hai. Adam jaise optimizers first steps mein correction karte hain. Long training mein correction ka effect chhota ho jaata hai.

β ko learning rate samjhun?

Nahi dost. Learning rate weight update ka kadam hai. β memory ka knob hai: purana kitna yaad, naya kitna suno.

v_1 = 0.9 × 0 + 0.1 × 50 = 5. Bias-corrected value 5/(1 − 0.9) = 50.
