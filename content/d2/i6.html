Deep network mein training kabhi start hi nahi hoti, kabhi loss blast ho jaata hai. Ye mood swings kyu?

Gehri chain mein same cheez baar-baar multiply hoti hai. Thoda sa 1 se bada number rocket ban sakta hai, thoda sa 1 se chhota number zero jaisa.

Matlab gradients bhi multiply hote-hote gayab ya explode?

Exactly. Isliye weights ko start mein sahi scale pe initialize karna bahut important hai.

Gehri linear network ka toy example

Real networks non-linear hote hain, par intuition ke liye simple chain lo. Agar har layer output ko 1.2 se multiply kare, 10 layers ke baad signal 1.2¹⁰ ≈ 6.19 ho jaata hai. Agar har layer 0.8 se multiply kare, 0.8¹⁰ ≈ 0.107. Dono directions depth badhne par training ko mushkil bana sakti hain.

Gradients pe bhi wahi asar

Backprop right se left aata hai. Har layer local slope se multiply karta hai. Agar slopes baar-baar 0.2, 0.3 jaise aaye, pehle layers tak gradient almost zero. Network ke early layers seekhenge hi nahi. Agar slopes/weights large aaye, updates huge ho sakte hain, loss NaN tak ja sakta hai.

Inputs zyada, weights chhote

Ek neuron ke paas n inputs hain. Agar n bada hai aur weights bhi bade random hain, to z = w₁x₁ + w₂x₂ + ... bahut bada ho sakta hai. z bahut bada hua to sigmoid/tanh saturation, gradients chhote. Isliye n_prev badhe to initial weights ka scale chhota karte hain.

n_prevHe scale √(2/n_prev)Xavier scale √(1/n_prev)
100√0.02 ≈ 0.141√0.01 = 0.100
400√0.005 ≈ 0.071√0.0025 = 0.050

He vs Xavier initialization

ReLU aadhe negative values ko zero kar deta hai, isliye uske liye slightly larger variance useful hota hai: Var(w) = 2/n. Tanh/sigmoid zero-centered smooth activations ke liye common choice Var(w) = 1/n, often Xavier/Glorot style.

ReLU layers: W = randn(shape) × √(2 / n_prev) tanh layers: W = randn(shape) × √(1 / n_prev)
  • randn = mean 0, variance 1 random numbers
  • n_prev = previous layer ke units / inputs
  • shape = (n_current, n_prev)
def init_layer(n_current, n_prev):
    W = np.random.randn(n_current, n_prev) * np.sqrt(2 / n_prev)
    b = np.zeros((n_current, 1))
    return W, b  # ReLU hidden layer ke liye He init

Initialization se training start hi better jagah se

Initialization perfect solution nahi dhoondhta. Bas starting point aisa rakhta hai jahan activations aur gradients ka scale sane ho. Uske baad optimizer learning karta hai. Galat init ka matlab car ko ya to dal-dal mein start karna, ya slope ke edge pe.

Dhyan rakhna: Saare weights zero se initialize mat karo. Same layer ke neurons identical rahenge, same gradient paayenge, aur same cheez seekhenge. Randomness symmetry todti hai.
Yaad rakhna: Deep network mein numbers lambi relay race daudte hain; initialization unhe na behosh hone deta, na overexcited.

Dimaag mein aaye sawaal

Bias b ko random initialize karna chahiye?

Usually nahi. b = 0 theek hai, kyunki symmetry weights se break ho chuki hoti hai.

He initialization sirf ReLU ke liye?

Mainly ReLU family ke liye popular hai. Tanh/sigmoid ke liye Xavier style common hai.

Batch norm ho to initialization matter nahi karta?

Matter kam ho sakta hai, par khatam nahi. Achhi initialization ab bhi stable start deti hai.
