Chatbot agla word kaise guess karta hai? Kya usko grammar rules diye jaate hain?

Rules se zyada examples. Usko bahut saare sentences dikhao. Phir woh seekhta hai: “chai” ke baad “piyo” aa sakta hai, “train” ke baad “late” aa sakta hai.

Toh language model fortune teller hai?

Haan, par calculator wala fortune teller. Har next token ko probability deta hai.

Language model kya karta hai: P(sentence)

Language model sentence ko ek probability deta hai. Natural sentence ko zyada chance, ajeeb sentence ko kam. “Aaj chai garam hai” ka chance “garam aaj hai chai” se zyada hona chahiye.

P(y₁, y₂, y₃) = P(y₁) · P(y₂ | y₁) · P(y₃ | y₁, y₂)
  • y₁ = pehla token.
  • P(y₂ | y₁) = pehla token dekh ke second ka chance.
  • Product = poore sentence ka chance, step-by-step.
StepTokenProbabilityRunning product
1aaj0.300.30
2chai | aaj0.500.30 × 0.50 = 0.150
3piyo | aaj chai0.100.015

Final P(sentence) = 0.015. Training mein log loss use karte hain: −log(0.30) − log(0.50) − log(0.10) = 4.200 ke aas-paas.

Corpus, tokenize, <EOS>, <UNK>

Corpus bas text ka collection hai: reviews, news, chat logs, recipes — jo bhi domain chahiye. Hum corpus ko tokens mein todte hain. Sentence ke end pe <EOS> lagate hain, unknown word ko <UNK>.

Raw text
“chai piyo”→Tokens
chai, piyo, <EOS>→RNN training
next token predict
tokens = ["aaj", "chai", "piyo", "<EOS>"]
for t in range(len(tokens) - 1):
    x_t = tokens[t]
    target = tokens[t + 1]
    print(x_t, "predicts", target)  # aaj predicts chai

RNN har step agla shabd softmax se predict karta hai

Input x⟨t⟩ dene ke baad RNN hidden state update karta hai, phir softmax vocabulary ke har token pe chance deta hai. Agar vocab 10,000 hai, output 10,000 probabilities ka vector.

Loss: har step ka cross-entropy

Agar sahi next token “chai” hai aur model ne usko 0.50 probability di, loss = −log(0.50). Agar sirf 0.01 diya hota, loss bahut bada. Cross-entropy model ko sahi token ka probability badhane pe push karta hai.

L⟨t⟩ = −log P(sahi next token at time t)
  • Probability high: loss low.
  • Probability low: loss high.
  • Total loss = saare time steps ka sum.

Sampling: naye sentences banana

Training ke baad model se sentence nikalna ho toh start token do, softmax probabilities se ek token sample karo, phir usko next input banao. Jab <EOS> aaye, ruk jao.

Sample karne se variety aati hai. Har baar max choose karoge toh model safe aur boring ho sakta hai — jaise har party mein sirf plain dosa.

Character-level vs word-level

Character-level
Vocabulary chhoti: a, b, c, space. Unknown word problem kam. Par sequence lambi, meaning seekhna mushkil.
Word-level
Sequence chhoti, word meaning clearer. Par vocabulary badi, <UNK> issue aata hai.
Dhyan rakhna: Sampling mein probability ko normal count mat samjho. 0.50 ka matlab guarantee nahi; bas long run mein lagbhag aadhi baar.
Yaad rakhna: Language model poore sentence ka chance next-token probabilities ke product se banata hai, aur naye text ke liye un probabilities se sample karta hai.

Dimaag mein aaye sawaal

<EOS> na lagayein toh?

Model ko sentence khatam karna properly nahi seekhega. Generation mein woh lamba bolta hi reh sakta hai.

Lowest loss ka matlab best creative text?

Zaroori nahi. Loss next-token prediction measure karta hai. Creative quality ke liye sampling temperature, data quality, aur evaluation bhi matter karte hain.

Softmax 10,000 words pe slow hai?

Haan, large vocab pe expensive hota hai. Word2Vec page mein negative sampling jaise shortcuts dekhenge.

✍️ Ab tumhari baari (pehle khud socho, phir answer kholna)

P(w₁)=0.2, P(w₂|w₁)=0.4, P(w₃|w₁,w₂)=0.5. Sentence probability?

0.2 × 0.4 × 0.5 = 0.04.

“namaste duniya” ko training pair mein kaise todoge, <EOS> ke saath?

Tokens: namaste, duniya, <EOS>. Pairs: namaste predicts duniya; duniya predicts <EOS>.

Word-level model mein unseen word aaye toh?

Use <UNK> token se replace karenge.
