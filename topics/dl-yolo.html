Sliding windows mein har jagah dekhna padta tha. YOLO ka naam kyun famous hai?

Kyuki YOLO bolta hai: “You Only Look Once.” Ek image, ek forward pass, aur saare boxes + classes. Jaise traffic police ek baar CCTV screen dekhe aur bole: car yahan, bike yahan, bus yahan.

Ek baar dekh ke kaise itne objects?

Image ko grid mein baanto. Har cell apne area mein object ka center aaye to us object ki zimmedari leta hai.

Grid: image ko mohalla-wise baant do

Maan lo image ko 4×4 grid mein baanta. Agar kisi object ka center right-middle cell mein hai, to wahi cell us object ka output predict karega. Object ka box cell se bahar bhi ja sakta hai — zimmedari center se decide hoti hai.

Har cell ka output

Ek anchor ke liye cell output familiar vector jaisa hai:

[p_c, b_x, b_y, b_h, b_w, c₁, c₂, c₃]
  • p_c = is anchor/cell mein object hai?
  • b_x,b_y = cell ke andar center position. Aksar 0 se 1 ke beech.
  • b_h,b_w = box height/width grid cell ke comparison mein. Ye 1 se bade ho sakte hain, kyunki object cell se bahar nikal sakta hai.
  • c₁,c₂,c₃ = class probabilities, jaise pedestrian/car/bike.

Agar cell 80×60 pixels ka hai aur object box 120×90 pixels ka hai, to b_w=120/80=1.5 aur b_h=90/60=1.5. Isme kuch galat nahi — dabba cell se bada hai.

IoU: do boxes kitne overlap karte hain?

Intersection over Union box quality check karta hai. Common area ko total covered area se divide karo. 1 matlab perfect same, 0 matlab touch bhi nahi.

IoU = overlap area ÷ union area
  • overlap = dono boxes ka common hissa
  • union = box A area + box B area − overlap

Worked example: Box A = (20,20) se (80,80), Box B = (30,30) se (90,90).

StepCalculationValue
A area60 × 603600
B area60 × 603600
Overlap(80−30) × (80−30)2500
Union3600 + 3600 − 25004700
IoU2500 ÷ 47000.532

Agar threshold 0.5 hai, to 0.532 pass. Agar threshold 0.75 hai, to fail. Same prediction, stricter exam.

Non-max suppression: duplicate boxes hatao

YOLO aksar ek hi car ke around 3-4 boxes de deta hai. Non-max suppression (NMS) bolta hai: “sabse confident box rakho, uske bahut similar boxes hatao.”

Low score boxes hatao→Highest score choose→High IoU duplicates delete↻Repeat

Anchor boxes: ek cell, do objects

Problem: ek cell mein pedestrian aur car dono ke centers aa gaye. Single output hota to fight ho jaati. Anchor boxes fix shapes ke templates hote hain — jaise tall-thin anchor pedestrian ke liye, wide anchor car ke liye.

Har cell ab ek nahi, B anchors ke outputs predict karta hai. Training mein object us anchor ko assign hota hai jiska shape uske box se best match karta hai (IoU high).

Anchor 1Tall box. Pedestrian, pole, bottle jaise shapes.
Anchor 2Wide box. Car, bus, sofa jaise shapes.

Poora YOLO tensor: 4×4×3×7

Mini setup lo: grid 4×4, anchors 3, classes 2. Har anchor output size = 7. Total output tensor:

4 × 4 × 3 × 7 = 336 numbers
  • 4×4 = grid cells
  • 3 = anchors per cell
  • 7 = p_c + 4 box numbers + 2 class numbers

Training mein target tensor bhi isi shape ka banta hai. Prediction time pe model scores deta hai, phir threshold + NMS se final clean boxes milte hain.

# YOLO prediction ka high-level flow
pred = model(image)              # shape: S, S, B, 5+C
boxes = decode_boxes(pred)       # bx,by,bh,bw ko image coords mein lao
boxes = keep_score_above(boxes, 0.4)
final = non_max_suppression(boxes, iou_threshold=0.5)
Dhyan rakhna: Class probability aur box confidence ko mix mat karo. Aksar final score = p_c × class probability hota hai. Box confident hai par class uncertain hai to final score low ho sakta hai.
Yaad rakhna: YOLO image ko grid mein baantta hai, anchors se multiple shapes handle karta hai, IoU se quality naapta hai, aur NMS se duplicates saaf karta hai.

Dimaag mein aaye sawaal

Object ka center boundary pe ho to kaunsa cell?

Implementation ek consistent rule use karti hai, jaise floor operation. Important baat: training aur prediction mein same coordinate convention follow ho.

bₕ,b_w 1 se bade kyu allowed?

Kyuki cell sirf owner decide karta hai. Object cell se bahar expand ho sakta hai. Ek bus ka center cell mein ho sakta hai, par bus teen cells tak fail sakti hai.

NMS class-wise hota hai ya sab boxes pe?

Aksar class-wise. Car box pedestrian box ko suppress na kare, warna overlapping log aur vehicles mein problem ho sakti hai.

Anchor boxes ka size kaise choose karte hain?

Training data ke boxes dekh ke common shapes choose karte hain, jaise k-means type clustering. Beginner ke liye intuition: dataset mein jo shapes baar-baar aate hain, anchors un jaise hone chahiye.

✍️ Ab tumhari baari (pehle khud socho, phir answer kholna)

Box A area 1000, Box B area 800, overlap 300. IoU?

Union = 1000 + 800 − 300 = 1500. IoU = 300/1500 = 0.20.

Grid 5×5, anchors 2, classes 4. Output tensor mein total numbers?

Har anchor output = 5 + classes = 9. Total = 5×5×2×9 = 450 numbers.

Ek cell mein car aur person dono ke center aa gaye. Anchor boxes kaise madad karte hain?

Wide anchor car ko, tall anchor person ko represent kar sakta hai. Isse ek cell ke andar do alag outputs mil jaate hain.
