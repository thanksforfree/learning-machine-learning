Ye kyu seekh rahe hain?Industry mein table data ke liye XGBoost aksar pehli pasand hai. Aur ye tay karna ki trees chunein ya neural network — engineer ka faisla.

Ek tree kaafi nahi? Itna bhi kya panchayat?

Ek tree bahut moody hota hai — data mein ek example badlo to pehla sawaal hi badal sakta hai aur poora tree alag ban jaata hai. Solution: bahut saare trees banao aur voting karao. Jaise ek dost ki raay pe film choose karne ki jagah 10 doston se puchho.

Par same data pe 10 trees to same hi banenge?

Isliye har tree ko thoda alag data dete hain — “sampling with replacement”. Ek thaili mein saare examples, ek nikaalo, note karo, wapas daal do, phir nikaalo. Kuch examples do baar aayenge, kuch ek baar bhi nahi. Har tree ka apna thoda alag dataset.

Tree 2: Aam
Tree 3: Nahi→Voting: Aam (2 vs 1)

Random forest

Upar wali trick + ek aur twist: har split pe saare features nahi, bas kuch random features mein se chuno. Isse trees aur alag-alag bante hain, aur panchayat ka faisla aur stable.

Boosting / XGBoost — galtiyon pe focus

Exam ki taiyaari socho: pehle poora mock test do. Phir jo sawaal galat hue, unko zyada practice karo. Phir naya test, phir galat wale pe zyada focus. Boosting yahi karta hai — har naya tree pichhle trees ki galtiyon pe zyada dhyan deta hai.

XGBoost (eXtreme Gradient Boosting) iska fast, bahut popular version hai jisme regularization bhi built-in hai. Table wale data ke competitions mein aksar jeet-ta hai — matlab Excel-type data ho to isko ignore mat karna.

from xgboost import XGBClassifier
model = XGBClassifier()
model.fit(X_train, y_train)
pred = model.predict(X_test)  # final mein honest test set pe

Sampling with replacement ko numbers se dekho

Replacement wala part thoda ajeeb hai. Wapas daal ke sample kyu?

Taaki har tree ko thoda alag duniya mile. Same size ka dataset banega, par kuch examples repeat honge aur kuch miss. Isi se trees mein diversity aati hai.

Maan lo original training examples [1, 2, 3, 4, 5, 6] hain. Ek tree ke liye 6 draws kiye, har draw ke baad example wapas daal diya.

DrawsTree ko mila dataRepeatOut-of-bag (nahi mila)
6[2, 2, 5, 1, 6, 2]2 teen baar3, 4
6[1, 3, 3, 4, 6, 6]3 aur 6 repeat2, 5

Har tree thoda alag data dekhta hai. Phir random feature subset ka twist add karo — ab trees aur bhi alag sochenge. Voting average karke moodiness kam ho jaati hai.

Dimaag mein aaye sawaal

Kitne trees banaye?

Aam taur pe 64 se 500 ke beech. Zyada trees se nuksaan kam hota hai, bas slow ho jaata hai. Ek point ke baad fayda band.

Random forest vs XGBoost — kaunsa pehle try karun?

Table data pe XGBoost aam taur pe thoda behtar hota hai. Par rule simple hai: dono try karo, CV set pe compare karo, phir decide. Andaz se model choose karna lottery hai.

Out-of-bag examples ka use kya?

Jo examples kisi tree ne training mein nahi dekhe, unpe us tree ko test kar sakte ho. Random forest mein isse extra validation signal milta hai.

XGBoost overfit kar sakta hai?

Haan. Isliye depth, learning rate, number of trees, regularization tune karte hain. Powerful model hai, magic shield nahi.
