Matrix gradients dekh ke lagta hai formula yaad karne padenge.

Formula ratna mat. Shape dekho. Gradient hamesha us cheez ke shape ka hota hai jiske liye gradient nikal rahe ho.

Matlab dW ka shape W jaisa?

Exactly. Agar W ka shape (1,2) hai to dW bhi (1,2). Ye ek rule tumhe aadhe formulas khud nikaalne dega.

* vs @ — dono multiply nahi hote

Element-wise *Same shape ke boxes pair-by-pair multiply. [2,3] * [10,20] = [20,60].
Matrix multiply @Rows aur columns ka dot product. Shapes ka rule: (a,b) @ (b,c) = (a,c).

Backprop mein dono aate hain. ReLU/tanh derivative ke saath *. Weight gradient ke liye mostly @.

Gradient ka shape rule

gradient of X has same shape as X
  • W shape (1,2) hai to dW shape (1,2).
  • b shape (1,1) hai to db shape (1,1).
  • Z shape (1,m) hai to dZ shape (1,m).

dZ = A − Y ka seedha matlab

Binary classifier mein final sigmoid + log loss ke baad ek beautiful shortcut aata hai: dZ = A − Y. Prediction minus actual. Agar model 0.8 bolta hai aur answer 1 hai, dZ = −0.2. Matlab z badhana chahiye. Agar model 0.3 bolta hai aur answer 0 hai, dZ = +0.3. Matlab z ghatana chahiye.

Shapes jod ke dW nikaalo

Chhota setup: 2 features, 3 examples. Is convention mein examples columns mein hain.

CheezShapeValue
X(2,3)[[1,2,3],[4,0,1]]
W(1,2)2 weights
Z, A, Y, dZ(1,3)har example ka ek output
dW(1,2)W jaisa hona hi hai

Ab dW ke liye dZ (1,3) aur X ka koi version chahiye jisse answer (1,2) aaye. dZ @ X.T gives (1,3) @ (3,2) = (1,2). Bas formula mil gaya.

dW = (1/m) × dZ @ Xᵀ db = (1/m) × sum(dZ, axis=1, keepdims=True)
  • m = examples ki count, yahan 3.
  • Xᵀ isliye, kyunki hume examples wali dimension 3 ko match karna hai.
  • db mein har example ki bias wali galti average hoti hai.

import numpy as np

X  = np.array([[1, 2, 3],
               [4, 0, 1]])       # (2, 3)
dZ = np.array([[-0.2, 0.3, -0.4]]) # (1, 3)
m = X.shape[1]
dW = dZ @ X.T / m
db = np.sum(dZ, axis=1, keepdims=True) / m
print(np.round(dW, 3))            # [[-0.267 -0.4  ]]
print(np.round(db, 3))            # [[-0.1]]

Backward mein transpose baar-baar kyu?

Forward mein agar Z = W @ X + b, to W ne X ko output side bheja. Backward mein gradient ko wapas input side bhejna hai, isliye W.T aata hai. Direction palat gayi, table bhi palat gayi.

Forward
W @ X→Z↻Backward
Wᵀ @ dZ

Deep learning mein ye kahan milega?

DL Course 1 ke logistic gradients, vectorized backprop, shallow network, aur L-layer dimensions pages mein. Course 2 ke gradient checking mein bhi dW/db shapes verify karne padte hain.

Dhyan rakhna: Agar dW ka shape W jaisa nahi aa raha, formula galat hai ya transpose missing hai. Pehle shape print karo, values baad mein dekho.
Yaad rakhna: Gradient same shape ka hota hai. Matrix formula confuse kare to sirf shapes multiply karke dekho; transpose wahi lagao jahan beech dimension match ho.

Dimaag mein aaye sawaal

dZ = A − Y hamesha hota hai?

Nahi. Ye special combo hai: sigmoid output + binary cross-entropy, ya softmax + cross-entropy mein similar dZ = Ŷ − Y. Har activation/loss ke liye same nahi.

db mein axis=1 kyu?

dZ shape (neurons, examples). Bias har neuron ka ek number hai, to examples ke across average chahiye. Examples axis 1 par hain.

Formula yaad na rahe to?

W ka shape likho. dZ ka shape likho. X ya Xᵀ mein se jo dW jaisa answer de, woh choose karo. Ye trick surprisingly reliable hai.

✍️ Ab tumhari baari (pehle khud socho, phir answer kholna)

W shape (4,5). dW ka shape?

Gradient same shape ka. (4,5).

dZ shape (4,10), A_prev shape (5,10). dW ke liye kya multiply karoge?

dZ @ A_prev.T: (4,10) @ (10,5) = (4,5).

A = 0.15, Y = 1. dZ?

A − Y = 0.15 − 1 = −0.85.
