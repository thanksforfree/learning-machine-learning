PCA kya hai? Naam hi darawna hai — Principal Component Analysis.

Haan, naam full professor mode mein hai. Simple kahani: tumhe ek teapot ki ek hi photo leke dost ko dikhani hai. Upar se photo lo — bas gol dikhega. Side se lo — handle, tonti, shape sab dikhega. Tumne woh angle chuna jahan se sabse zyada information dikhe.

PCA yahi karta hai data ke saath: 50 features ko 2–3 “naye features” mein samet deta hai, aise angle se jahan data sabse zyada phaila (spread) dikhe. Phir tum usko graph pe dekh sakte ho.

Simple example: 2 features → 1

Gaadiyon ka data: x₁ = lambai, x₂ = chaudai. Dono saath-saath badhte hain (lambi gaadi aam taur pe chaudi bhi). Dots ek tirchhi line ke aas-paas hain.

1. Average 0 karo; zaroorat ho to scale→2. Woh direction dhundho jahan spread sabse zyada→3. Har point ko us line pe project karo

Project karna = har dot se line pe seedha (90°) shadow girana. Shadow ki jagah = naya number z. Jaise dopahar mein dhoop padti hai aur cheez ki shadow zameen pe aati hai. Doosra component pehle ke 90° pe hota hai, teesra dono ke 90° pe… jitne chahiye utne.

Code mein

from sklearn.decomposition import PCA
pca = PCA(n_components=2)
Z = pca.fit_transform(X)                 # 50 features → 2
print(pca.explained_variance_ratio_)     # jaise [0.72, 0.18] → 90% spread bacha
X_approx = pca.inverse_transform(Z)      # wapas original ka andaaza

PCA kab use karein?

Aaj kal mostly: visualization50 features wale data ko 2D graph mein dekhna — groups/patterns aankh se samajhne ke liye.
Pehle zyada use hota thaData compress karna, ya training fast karne ke liye features kam karna. Aaj ke fast computers aur deep learning mein ye kam zaroori.
PCA linear regression nahi hai: Linear regression ek target y predict karta hai (vertical galti). PCA ka koi y nahi — woh sabhi features ko barabar treat karke unka structure dhundhta hai (line pe seedhi 90° doori). Dono mein line dikhti hai, par kaam alag hai.

Projection ka numeric feel

Shadow wali baat achhi hai, par z number nikalta kaise hai?

Agar direction unit vector ho, to z = point · direction. Dot product hi shadow ki length deta hai.

Direction maan lo u = [0.71, 0.71] — roughly 45° ka unit vector. Is chhote hisaab mein points pehle se average-0 centered hain; PCA projection se pehle data ko center karta hai.

Point xz = x·uMeaning
[2, 2]2×0.71 + 2×0.71 = 2.84Line pe aage
[3, 1]3×0.71 + 1×0.71 = 2.84Same shadow length
[1, 0]1×0.71 + 0 = 0.71Chhota projection

Notice [2,2] aur [3,1] ka z same aaya. PCA compression mein kuch detail lost hoti hai — dono original points alag the, par 1D shadow same. Trade-off yahi hai: kam dimensions, thodi information loss.

Scale pe dhyan: PCA har feature ko automatically center karta hai, scale nahi. Agar units/ranges bahut alag hon — jaise height centimeters aur income rupees — to pehle scale karo; warna income spread “best angle” pe haavi ho sakta hai.
Yaad rakhna: PCA = data ki best “photo angle” dhundh ke bahut features ko kam naye features mein samet-na.

Dimaag mein aaye sawaal

Naye features (z₁, z₂) ka matlab kya hai?

Aksar mix hota hai (jaise z₁ ≈ “gaadi ka overall size”). Kabhi naam de pate ho, kabhi nahi.

Kitne components rakhun?

Visualization ke liye 2 ya 3, kyunki screen bhi 2D/3D hi dikhati hai. Doosre kaam ke liye itne ki explained variance ka total ~90–95% ho jaye.

PCA se model accuracy badhegi?

Guarantee nahi. Aajkal PCA mostly visualization ke liye use hota hai. Accuracy ke liye CV set pe compare karo — with PCA vs without PCA.

PCA supervised hai kya?

Nahi. PCA y labels nahi dekhta. Bas X features ka spread dekhta hai aur best directions choose karta hai.

PCA ko target y chahiye?

Nahi — ye unsupervised hai.
