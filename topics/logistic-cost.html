Cost function wahi squared error wala use kar lein?

Sigmoid ke saath squared error lagao to katori nahi banti — lehrati hui zameen banti hai jisme bahut saare chhote gaddhe hote hain. Gradient descent kisi galat gaddhe mein phas sakta hai.

To naya cost kaisa?

Idea bahut insaani hai. Ek dost bola “100% pakka kal baarish nahi hogi” aur baarish ho gayi — uski baat pe bharosa zero. Doosra bola “50-50 hai” — woh utna galat nahi tha. To: confident ho ke galat nikle to bahut badi saza, thoda unsure ho ke galat nikle to chhoti saza.

Matlab overconfidence pe fine lag raha hai?

Bilkul. Log loss model ko bolta hai: “confident banna hai to sahi jagah ban, warna bill bada aayega.”

Numbers dekho — email sach mein spam hai (y = 1)

Agar asli answer y = 0 hai (spam nahi), to ulta: loss = −log(1 − f). Model jitna zyada “spam” bolega, utni zyada saza.

L = −y · log(f) − (1 − y) · log(1 − f)
  • Trick: y = 1 ho to doosra hissa (1 − y = 0) gayab. y = 0 ho to pehla hissa gayab. Ek formula, dono case.
  • Cost J = saare examples ke L ka average. Ye katori jaisa hota hai → gradient descent safe.

Gradient descent ka update formula dikhne mein bilkul linear regression jaisa hi lagta hai — bas ab f ke andar sigmoid hai.

Cost = losses ka average

Squared error se intuition compare

Beginner doubt genuine hai: “galti to galti hai, square kyu nahi?” Classification mein hume probability ki quality chahiye.

Squared errorNumber prediction ke liye mast. Par sigmoid ke saath training surface messy ho sakti hai.
Log lossSahi class ko low probability dene pe heavy penalty. Classification ke confidence ko better train karta hai.

Isliye logistic regression mein log loss standard hai. Tumhe formula ratna nahi; bas behaviour yaad: confident galti = mehenga bill.

Yaad rakhna: Log loss poochta hai — “sahi answer ko tumne kitna chance diya tha?” Kam diya to zyada loss.

Dimaag mein aaye sawaal

log simple bhasha mein kya hai?

Tumhe bas iski shape pata honi chahiye: log(1) = 0 (koi saza nahi), aur number jitna 0 ke kareeb jaata hai, −log utna bada hota jaata hai. Isi se “confident galti = badi saza” wala behaviour aata hai.

Ye formula ratna padega?

Nahi. Meaning yaad rakho. Code mein library ka ek naam likhna hota hai (jaise BinaryCrossentropy).

“Cross-entropy” aur “log loss” alag hain?

Nahi, haan/na wale problems ke liye binary cross-entropy aur log loss same cheez ke do naam hain.

Loss itna bada kyu ho sakta hai?

Kyuki agar sahi answer ko model almost 0 chance de, to −log almost infinity ki taraf bhaagta hai. Isliye code mein probabilities ko kabhi-kabhi chhote safe range mein clip karte hain.

Accuracy achhi ho to log loss dekhna zaroori hai?

Haan. Do models dono 90% accurate ho sakte hain, par ek galat answers pe 0.51 confidence rakhta hai aur doosra 0.999. Log loss doosre ko zyada punish karega — confidence quality dikhti hai.

Log loss zero kab hota hai?

Sirf tab jab model har example pe sahi class ko 100% chance de. Real data mein noise hota hai, isliye exact zero expect mat karo. Cost ka trend neeche aa raha hai ya nahi, woh zyada useful signal hai.

✍️ Ab tumhari baari (pehle khud socho, phir answer kholna)

y = 1. f = 0.99 aur f = 0.01 pe loss?

≈ 0.01 aur ≈ 4.6.

y = 0 ho to formula ka kaunsa hissa bachta hai?

−log(1 − f).
