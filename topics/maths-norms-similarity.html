Vector ki “lambai” ka kya matlab? Vector to list hai.

Map pe ek arrow socho. Right 3 kadam, up 4 kadam. Arrow ki seedhi lambai 5 hoti hai. Wahi vector norm.

Aur similarity?

Do arrows same direction mein dekh rahe hain ya ulte? Cosine similarity angle se yahi batati hai.

L2 norm, L1 norm, squared L2

Vector v = [3, −4] lo. Ye ek chhota route hai: 3 right, 4 down.

Frobenius norm — matrix ki lambai

Matrix ke liye same idea: saare numbers square karo, jodo, root lo. Matrix [[1,2],[2,2]] ka Frobenius norm = √(1 + 4 + 4 + 4) = √13 ≈ 3.606.

||A||_F = √(Σ over all rows and columns Aᵢⱼ²)
  • Neural network mein W matrix hota hai.
  • L2 regularization aksar W ke squared Frobenius norm ko cost mein add karta hai.

Cosine similarity — direction same hai?

Distance size se affect hoti hai. Cosine similarity direction dekhti hai. Agar dono arrows same direction mein hain to 1, seedhe opposite to −1, 90° pe 0.

cosine_similarity(a,b) = (a · b) ÷ (||a||₂ × ||b||₂)
  • a · b = dot product.
  • ||a||₂ aur ||b||₂ = dono vectors ki L2 lambai.
  • Answer −1 se 1 ke beech hota hai.

Unit length pe normalize karna

Normalize = vector ko apni lambai se divide karo. [3,4] ki L2 lambai 5 hai, to unit vector [3/5, 4/5] = [0.6, 0.8]. Ab lambai 1 ho gayi.

import numpy as np

v = np.array([3, 4])
norm = np.linalg.norm(v)        # 5.0
unit = v / norm                 # [0.6, 0.8]

a = np.array([1, 2])
b = np.array([2, 1])
cos = np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b))
print(cos)                      # 0.8

Deep learning mein ye kahan milega?

  • L2 regularization: weights ki lambai chhoti rakhna.
  • Gradient checking: numerical gradient aur backprop gradient ki distance compare karna.
  • Face recognition: do face encodings ki distance.
  • Word embeddings: cosine similarity se “king” aur “queen” jaise vectors compare karna.
Dhyan rakhna: Cosine similarity calculate karte waqt zero vector se divide nahi kar sakte. Norm 0 ho to direction defined hi nahi.
Yaad rakhna: Norm = vector ki size, distance = do vectors ke beech ka gap, cosine = direction ki similarity.

Dimaag mein aaye sawaal

L1 aur L2 mein kaunsa better?

“Better” problem pe depend karta hai. L2 smooth hai aur deep learning mein common. L1 kuch weights ko exact zero ki taraf push karta hai, jo sparse models mein useful hota hai.

Squared L2 kyu use karte hain?

Root avoid ho jaata hai, derivative clean hota hai, aur bade weights ko zyada saza milti hai. Regularization mein ye convenient hai.

Cosine similarity distance se kab better?

Jab size nahi, direction matter kare. Text embeddings mein sentence lamba-chhota ho sakta hai, par meaning direction se pakadna hota hai.
