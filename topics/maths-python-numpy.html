5. NumPy — ML ka asli hathiyaar

Python list pe math ek-ek karna padta hai. NumPy array pe poori list pe ek saath kaam ho jaata hai (vectorized) — jaise ek-ek chai banane ke bajay canteen wali badi ketli.

import numpy as np

x = np.array([800, 1200, 1600])
print(0.04 * x + 10)          # [42. 58. 74.] — bina loop!

w = np.array([0.04, 3])
house = np.array([1200, 3])
print(np.dot(w, house) + 10)  # 67.0

X = np.array([[1200, 3],      # 2D: har row ek ghar
              [800,  2]])
print(X.shape)                # (2, 2)
print(X @ w + 10)             # [67. 48.] — dono ghar ek saath
print(np.mean(x), np.std(x))  # average aur σ
