Dropout naam se lagta hai college attendance wali problem hai.

Bilkul! Training ke dauraan kuch neurons ko bolte hain: “Aaj tum chhutti pe.” Baaki network ko kaam chalana padta hai.

Par jaan-boojh ke neurons band karna loss badha dega na?

Short term mein haan, par long term mein network jugaadu aur less dependent banta hai. Cricket team ki tarah: sirf ek star batsman pe bharosa nahi.

Idea: training mein random neurons band

Dropout regularization ka simple idea hai: har training step mein layer ke activations ka random subset zero kar do. Agle mini-batch mein alag subset zero hoga. Network har baar ek thoda different, thoda chhota network ban ke train hota hai.

Inverted dropout: mask, keep_prob, scale

Sabse common implementation inverted dropout hai. keep_prob ka matlab: ek neuron active rehne ka chance. Agar keep_prob = 0.85, to roughly 85% activations bachenge. Jo bachenge unko 1/keep_prob se divide karte hain, taaki average activation same scale pe rahe.

D = random mask where D < keep_prob A = A * D A = A / keep_prob
  • D = 0/1 mask, same shape as activation A
  • keep_prob = neuron ko rakhne ka chance
  • A / keep_prob = test time scale match karne ki trick

Test time pe dropout nahi

Prediction ke time randomness nahi chahiye. Agar same photo ko 5 baar do, 5 alag answers aana ajeeb hoga. Isliye test/dev/inference time pe dropout off. Inverted dropout ki wajah se extra scaling bhi nahi karni padti.

TrainingRandom mask on. Activations scale by 1/keep_prob. Network ko redundancy seekhni padti hai.
TestingMask off. Full network use hota hai. Output stable rahta hai.

Kaam kyu karta hai?

Dropout network ko bolta hai: “Kal tumhara favourite neuron absent ho sakta hai.” To layer kisi ek feature pe over-dependent nahi hoti. Agar face detector sirf “left eye bright” feature pe depend kar raha tha, dropout usko nose, outline, texture jaise backup clues bhi use karna sikhata hai.

Ek aur intuition: dropout many smaller networks ka average jaisa behave karta hai. Alag-alag masks se alag networks train hote hain, aur test time full network un sab ka blended version jaisa hota hai.

Har layer ka alag keep_prob

Jis layer mein parameters zyada aur overfitting risk zyada, wahan keep_prob thoda kam kar sakte ho. Input layer pe usually zyada aggressive dropout nahi lagate. Kuch layers pe dropout zero bhi ho sakta hai, matlab keep_prob = 1.

LayerPossible keep_probReason
Input0.95 ya 1.0Raw data ko zyada mat todo
Big hidden layer0.7–0.9Overfit risk high
Small hidden layer0.9–1.0Already limited capacity

Cost J ab clean define nahi — debug kaise karein

Dropout ke saath har iteration mein network random change hota hai, to exact cost curve noisy aur hard-to-interpret ho sakta hai. Agar loss decrease nahi ho raha, pehle dropout off karke check karo ki basic network overfit kar pa raha hai ya nahi. Phir dropout on karo.

Dhyan rakhna: Dropout ko har problem pe default namak ki tarah mat daalo. Agar high bias hai, dropout aur badha sakta hai. Dropout mainly high variance ke liye hai.
Yaad rakhna: Dropout training mein thodi pareshaani deke network ko less nakhrebaaz banata hai.

Dimaag mein aaye sawaal

keep_prob 0.8 ka matlab 80% weights rakhna?

Nahi, usually activations/neurons ko mask karte hain. Weights delete nahi hote; bas us pass mein unka contribution zero ho jaata hai.

Dropout convolution layers mein bhi use hota hai?

Hota hai, par CNNs mein data augmentation aur batch norm bhi strong tools hain. Fully connected layers mein dropout zyada common dikhta hai.

Randomness se result unstable nahi hoga?

Training stochastic hoti hai, par test time dropout off hota hai. Seed set karoge to experiment repeatable bhi ban sakta hai.

✍️ Ab tumhari baari (pehle khud socho, phir answer kholna)

A = 0.6, mask = 1, keep_prob = 0.75. Inverted dropout ke baad value?

0.6 × 1 ÷ 0.75 = 0.8. final answer: 0.8.

Dev pe predict karte waqt dropout on ya off?

Off. Dev/test/inference time pe full network use karo.

High bias model pe dropout badha diya. Kya risk?

Model aur weak ho sakta hai, training error badh sakta hai. Pehle capacity/optimization fix karo.
