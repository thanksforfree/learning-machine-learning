Mera model train pe mast, dev pe thoda drama. Overfit lag raha hai. Ab kya?

Socho school ka topper har answer mein 4 page likhta hai. Teacher bole: “Bhai, point pe aao.” L2 regularization bhi weights ko wahi bolta hai.

Weights ko chhota rakhne se overfitting kaise rukta hai?

Bade weights model ko bahut tez, tedha-medha decision boundary banane dete hain. L2 bolta hai: useful pattern seekho, par hawa mein talwar mat ghumaao.

Logistic regression mein L2

Normal cost training errors ka average hota hai. L2 usme ek extra fine jodta hai: weights bade honge to fine zyada. Bias b ko aam taur pe fine nahi karte, kyunki b sirf whole line ko shift karta hai.

J = normal cost + (λ / 2m) × Σ wⱼ²
  • λ (lambda) = regularization ki strength, knob tum choose karte ho
  • m = training examples ki count
  • Σ wⱼ² = saare weights ke squares ka total
ExampleValue
m = 4, λ = 0.2, weights = [3, 4]Σw² = 9 + 16 = 25
Extra L2 fine0.2 ÷ (2 × 4) × 25 = 0.625

L1 regularization thoda alag hai: Σ |wⱼ|. Ye kai weights ko exactly zero bana sakta hai, matlab feature selection jaisa effect. Deep learning mein everyday default L2 zyada common hai.

Neural network mein Frobenius norm

Network mein weights matrix hote hain: W[1], W[2], ... L2 ka same idea matrix pe lagta hai. Matrix ke saare numbers square karo, add karo. Isko Frobenius norm squared bolte hain. Naam fancy hai, kaam simple: poori weight table ki “energy” naapna.

Backprop mein extra term: weight decay

L2 add karne ke baad gradient mein ek extra term aata hai: (λ/m)W. Update dekh ke naam samajh aata hai. Har step weight thoda shrink hota hai, isliye log isko weight decay bhi bolte hain.

dW = dW_from_loss + (λ/m)W W := W − αdW
  • dW_from_loss = normal backprop se aaya slope
  • (λ/m)W = L2 ki wajah se shrink karne wali push
  • α = learning rate
WdW lossλ/m × WNaya W, α = 0.1
50.4(0.6/10)×5 = 0.35 − 0.1×0.7 = 4.93
m = X.shape[1]
lambd = 0.6
dW = dW_from_backprop + (lambd / m) * W  # L2 ka extra push
W = W - learning_rate * dW               # weight thoda decay hota

Overfitting kaise ghat-ta hai — do intuitions

Boundary smooth hotiBade weights model ko har chhoti noise ke around bend karwa dete hain. L2 boundary ko “thoda shaant” rakhta hai.
Neurons kam dramaticWeights chhote honge to z values moderate rahenge. Network har input pe extreme confidence nahi dikhayega.

Ek aur view: λ bahut bada kar diya to weights almost zero. Network ke layers weak signal bhejenge, aur model simple ho jayega. Simple model overfit kam karega, par zyada simple hua to underfit.

Debug: cost plot mein regularization term bhi jodo

Agar tum training cost print kar rahe ho, to same cost print karo jisko model optimize kar raha hai. L2 use kar rahe ho aur plot mein regularization term bhool gaye, to graph misleading ho sakta hai. Loss wala part kabhi-kabhi down ja raha, par total objective different behave kar raha hoga.

Dhyan rakhna: Regularization lagate waqt dev/test cost report karne ka tareeka consistent rakho. Training ke optimizer objective mein L2 hota hai; model performance compare karte waqt aksar raw prediction loss/metric bhi alag se dekhte hain.
Yaad rakhna: L2 model ko “pattern seekho, par weights ko hero mat banao” wali gentle warning deta hai.

Dimaag mein aaye sawaal

λ ka best value kaise choose karun?

Dev set pe try karo: 0, 0.01, 0.03, 0.1, 0.3, 1... Log scale pe. Train pe nahi, dev pe decide.

Bias b ko regularize kyu nahi karte?

b poori boundary ko shift karta hai, complexity zyada nahi badhata. Regularize kar bhi do to usually farak chhota, par standard practice b ko chhodna hai.

L2 aur dropout saath use kar sakte hain?

Haan, par pehle simple rakho. L2 se start karo, phir zaroorat ho to dropout add karo. Har knob ek saath ghumaya to diagnosis mushkil ho jayega.

✍️ Ab tumhari baari (pehle khud socho, phir answer kholna)

m = 5, λ = 0.1, weights [2, −1, 3]. L2 extra cost?

Σw² = 4 + 1 + 9 = 14. Extra = 0.1 ÷ (2×5) × 14 = 0.14. final answer: 0.14.

λ bahut bada kar diya. Train error bhi badh gaya. Kya hua?

Model ko bahut zyada simple bana diya. Ye high bias / underfitting ki taraf ja raha hai.

L1 kya special kar sakta hai?

Kai weights exactly zero kar sakta hai, isliye kuch features effectively ignore ho jaate hain.
