  • Computation graph: forward left se right, backward right se left
  • Har node pe local slope × peeche se aaya slope (chain rule)
  • Sigmoid ka derivative σ(1 − σ) numbers ke saath, max slope 0.25
  • tanh ka derivative 1 − tanh², ReLU ka 0 ya 1

Backprop sunte hi lagta hai koi secret magic hai.

Magic nahi, bas grocery bill ka reverse audit. Forward mein bill bana, backward mein pata kiya kis item ne bill ko kitna badhaya.

Matlab har step ka “zimmedari score”?

Bilkul. Computation graph mein calculation ko chhote boxes mein todte hain. Phir chain rule se right se left slopes bhejte hain.

Computation graph — forward left se right

Ek example lo: J = (a + b) c. Pehle chhote steps banao.

b = 1→u = a + b = 6→J = u c = 18

Backward — right se left zimmedari baanto

Backward ka rule simple hai: local slope × peeche se aaya slope. Agar J ko u se 3 guna farak padta hai, aur u ko a se 1 guna, to J ko a se 3 × 1 = 3 guna farak.

GradientHisaabMeaning
dJ/du3u 1 badhe to J 3 badhe
dJ/dc6c 1 badhe to J 6 badhe
dJ/da3 × 1 = 3a 1 badhe to J 3 badhe
dJ/db3 × 1 = 3b 1 badhe to J 3 badhe
upstream gradient × local derivative = current gradient
  • upstream = right side se aayi zimmedari.
  • local derivative = is node ke andar ka chhota slope.
  • Yehi chain rule hai, bas graph pe likha hua.

Activation derivatives — network ke gates ka slope

Neuron pehle z banata hai, phir activation a. Backprop ko activation ka slope chahiye: z thoda badhe to a kitna badhega?

Saturation — “bahut sure” neuron ka problem

Sigmoid mein z bahut positive ho to output almost 1. Bahut negative ho to almost 0. Dono jagah curve flat hai. Example: z = −4 pe sigmoid ≈ 0.018 aur slope ≈ 0.0177. Gradient itna chhota ho to peeche layers tak signal kam pahunchta hai.

import numpy as np

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

z = np.array([0, 2, -4])
a = sigmoid(z)
da_dz = a * (1 - a)          # sigmoid derivative
print(np.round(a, 3))        # [0.5   0.881 0.018]
print(np.round(da_dz, 3))    # [0.25  0.105 0.018]

Deep learning mein ye kahan milega?

DL Course 1 ke computation graph, activation functions, shallow network backprop, aur Course 2 ke vanishing gradients page mein. ReLU isliye popular hai kyunki positive side pe slope 1 rehta hai.

Dhyan rakhna: Backward pass mein local slope bhool gaye to gradient galat. ReLU ke liye bhi mask lagta hai: jahan z ≤ 0 tha, wahan gradient 0.
Yaad rakhna: Forward values banata hai; backward slopes baant-ta hai. Har node ka rule: peeche se aaya gradient × local slope.

Dimaag mein aaye sawaal

Computation graph draw karna zaroori hai?

Haath se har baar nahi. Par jab formula confusing ho, graph bana ke nodes tod do. Backprop suddenly seedha lagne lagega.

Sigmoid ka max slope 0.25 kyu?

Derivative a(1 − a) hai. Ye product sabse bada tab hota hai jab a = 0.5: 0.5 × 0.5 = 0.25.

ReLU z = 0 pe derivative kya?

Maths mein thoda awkward point hai. Practice mein frameworks usually 0 le lete hain. Ek point se training pe farak nahi padta.

✍️ Ab tumhari baari (pehle khud socho, phir answer kholna)

J = 5u, u = x + 2. dJ/dx?

dJ/du = 5, du/dx = 1. To dJ/dx = 5.

Sigmoid output a = 0.9 hai. Derivative?

a(1 − a) = 0.9 × 0.1 = 0.09.

ReLU input z = −7 tha. Backward mein gradient aage bhejna hai?

Nahi. Negative side pe ReLU flat hai, local slope 0. Gradient 0 ho jaayega.
