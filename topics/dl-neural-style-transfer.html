Neural style transfer matlab meri selfie ko Madhubani painting jaisa bana dena?

Haan, par sirf filter lagana nahi. Model ek photo ka content rakhta hai aur doosri image ka style churaata hai — jaise tumhari gali ka scene, par rangoli ke patterns mein.

CNN ko art ka style kaise samajh aata hai?

CNN ki layers image ke alag clues pakadti hain. Shallow layers edges aur colors, deeper layers textures aur objects. Style transfer in activations ke saath khelta hai.

Teen images: C, S, G

Content CJiski structure rakhni hai: tumhari photo, India Gate, office desk.
Style SJiska rang-texture lena hai: Madhubani, Warli, rangoli, oil painting.
Generated GPixels jo optimize honge. Target: C jaisa layout, S jaisi feel.

Interesting twist: yahan model ke weights train nahi ho rahe. Pretrained CNN fixed hai. Hum image G ke pixels ko gradient descent se update karte hain.

ConvNet andar kya dekh raha hota hai?

Layer 1 ke filters simple edges, color blobs, corners jaise low-level clues pe fire karte hain. Thodi deeper layers textures: brick wall, cloth pattern, leaves. Aur aur deeper layers object parts: wheel, eye, window, face-like shapes. Isliye content ke liye deeper layer useful, style ke liye multiple shallow-to-mid layers useful.

Total cost: content aur style ka tug-of-war

Generated image G ko do teachers check karte hain. Content teacher poochta hai: “scene C jaisa hai?” Style teacher poochta hai: “texture/colors S jaise hain?”

J(G) = α J_content(C,G) + β J_style(S,G)
  • α = content ko kitna importance
  • β = style ko kitna importance
  • Gradient descent weights pe nahi, G ke pixels pe chalta hai.

α zyada rakho to photo original jaisi rahegi. β zyada rakho to style heavy ho jayega — kabhi-kabhi face bhi rangoli mein kho jaata hai.

Content cost: activations ka farak

Ek chosen deep layer lo. Content image C aur generated image G ko CNN se pass karo. Us layer ki activations compare karo. Agar activations similar hain, network ko dono ka structure similar lag raha hai.

J_content = ½ × Σ(a_C − a_G)²
  • a_C = chosen layer pe content image ki activations
  • a_G = same layer pe generated image ki activations

Mini numbers: a_C=[1,2], a_G=[1.5,1.0]. Cost = ½×((−0.5)² + 1²) = ½×1.25 = 0.625.

Style cost: Gram matrix se texture ki dosti

Style sirf “ye pixel red hai” nahi. Style mein patterns hote hain: kaunse channels saath-saath activate hote hain. Gram matrix channels ki correlation batata hai.

Maan lo ek layer mein 2 channels aur 3 positions hain:

F = [[1, 2, 0], [0, 1, 3]] Gram = F Fᵀ = [[5, 2], [2,10]]
  • 5 = channel 1 ki self-energy: 1²+2²+0²
  • 10 = channel 2 ki self-energy: 0²+1²+3²
  • 2 = dono channels saath kitne active: 1×0 + 2×1 + 0×3

Style cost S aur G ke Gram matrices ka difference hota hai. Aksar style ko kai layers pe measure karte hain: shallow layers color/brush strokes, deeper layers larger texture motifs.

Pixels pe gradient descent

Process thoda ulta lagta hai: random noise ya content image se G start karo. CNN fixed rakho. Cost nikalo. Phir G ke pixels ko thoda update karo taaki content aur style dono better match ho.

G = tf.Variable(content_image)     # pixels trainable hain
for step in range(steps):
    with tf.GradientTape() as tape:
        acts = vgg(G)
        loss = alpha * content_loss(acts) + beta * style_loss(acts)
    grad = tape.gradient(loss, G)
    optimizer.apply_gradients([(grad, G)])
    G.assign(tf.clip_by_value(G, 0, 1))

1D aur 3D convolution bhi hoti hai

Convolution sirf photos ke liye nahi. 1D convolution time signals pe chal sakti hai: ECG, audio waveform, sensor readings. Filter time axis pe slide hota hai. 3D convolution CT scan volume ya video clips pe use hoti hai — height, width, aur depth/time teen axes pe filter slide karta hai.

DataConv typeExample

Dhyan rakhna: Style transfer mein generated image ko train karte waqt CNN ko accidentally trainable mat chhod dena. Agar weights badal gaye, “teacher” khud answer key badalne lagega.
Yaad rakhna: Style transfer fixed CNN ke activations se content structure aur Gram matrices se style texture compare karta hai, phir generated pixels ko optimize karta hai.

Dimaag mein aaye sawaal

Style ke liye Gram matrix hi kyu?

Kyuki style location-specific nahi hota. Madhubani pattern photo ke kis corner mein hai, utna important nahi; channels ka saath-saath activate hona important hai. Gram matrix location ko average karke co-activation pakadta hai.

Generated image random noise se start karni chahiye ya content image se?

Dono possible. Content image se start karoge to structure jaldi stable rehta hai. Noise se start karoge to style zyada free ho sakta hai, par optimize karna mushkil.

β bahut bada rakha to kya hoga?

Style dominate karega. Colors/textures strong honge, par content object distort ho sakta hai. Jaise chai mein elaichi itni daal di ki chai ka taste hi gaya.

✍️ Ab tumhari baari (pehle khud socho, phir answer kholna)

a_C=[2,0], a_G=[1,3]. J_content = ½Σ(a_C−a_G)² kitna?

Differences: 1 aur −3. Squares: 1 aur 9. Sum=10. Half = 5.

F ke channels [1,1] aur [2,0] hain. Gram matrix?

G₁₁=1²+1²=2, G₂₂=2²+0²=4, G₁₂=1×2+1×0=2. Matrix [[2,2],[2,4]].

ECG signal ke liye 1D, 2D ya 3D convolution?

Usually 1D convolution, kyunki signal time axis pe ek sequence hota hai.
