RNN memory rakhta hai, phir bhi long sentence mein bhool kyu jaata hai?

Socho dost ne 2 minute pehle bola “ladki”, phir beech mein 20 words aa gaye, aur end mein verb choose karna hai: “gayi” ya “gaya”. Normal RNN ka signal raste mein halka pad sakta hai.

Matlab grammar ki lambi dor toot jaati hai?

Exactly. GRU ek gate lagata hai: “ye baat important hai, ise memory mein sambhal ke rakho.”

Lambi dependency: “ladka gaya” vs “ladki gayi”

Sentence dekho: “Woh ladki jo kal station pe apni chhoti behen ke saath khadi thi, ghar gayi.” Verb “gayi” ko start ke “ladki” se agreement chahiye. Beech ka pura masala distract kar sakta hai.

RNN mein vanishing gradients

BPTT mein gradient time mein peeche travel karta hai. Agar har step pe woh 0.8 se multiply hota raha, toh 10 steps baad 0.8¹⁰ ≈ 0.107. Signal bahut chhota. Model ko pata hi nahi chalega ki start wale word ko kaise adjust karna tha.

Steps peecheGradient factorSignal
10.80.800
50.8⁵0.328
100.8¹⁰0.107

Isko vanishing gradient bolte hain. Lambi dependency seekhna slow ya impossible jaisa lagne lagta hai.

Exploding gradients aur clipping

Kabhi ulta hota hai: har step pe 1.5 se multiply, toh signal rocket ban jaata hai. Weights wild jump maarte hain, loss NaN tak pahunch sakta hai. Simple safety: gradient ko max size ke andar clip kar do.

agar ||g|| > threshold, toh g = threshold × g / ||g||
  • g = gradient vector.
  • threshold = allowed max norm, jaise 5.
  • Direction same rehti hai, bas size control mein.
loss.backward()
torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=5.0)
optimizer.step()  # exploding gradient ko leash laga di

GRU: memory cell aur candidate

GRU ka full naam Gated Recurrent Unit. Isme memory cell c⟨t⟩ hota hai. Har step pe model ek candidate c̃⟨t⟩ banata hai: “agar nayi info accept karni ho, toh memory aisi ho sakti hai.”

c̃⟨t⟩ = tanh(W_c [Γᵣ * c⟨t−1⟩, x⟨t⟩] + b_c)
  • c̃⟨t⟩ = proposed new memory.
  • c⟨t−1⟩ = purani memory.
  • Γᵣ = relevance gate; purani memory ka kitna hissa candidate banate waqt relevant hai.

Update gate Γᵤ: naya likhna ya purana sambhalna?

GRU ka star gate update gate hai. Γᵤ 0 aur 1 ke beech number hai. 1 ke paas: nayi candidate memory likho. 0 ke paas: purani memory bachao.

Γᵤ = sigmoid(W_u [c⟨t−1⟩, x⟨t⟩] + b_u) c⟨t⟩ = Γᵤ * c̃⟨t⟩ + (1 − Γᵤ) * c⟨t−1⟩
  • Γᵤ ≈ 0 = yaad rakho, overwrite mat karo.
  • Γᵤ ≈ 1 = nayi info strong hai, update karo.
CaseΓᵤc̃c oldc new
Gate mostly closed0.20.70.60.2×0.7 + 0.8×0.6 = 0.62
Gate mostly open0.90.10.60.9×0.1 + 0.1×0.6 = 0.15

Gate closed mein memory lagbhag 0.6 hi rahi. Gate open mein nayi candidate 0.1 ne memory ko kheench liya. Ye hi long memory ka control knob hai.

Full GRU: relevance gate Γᵣ

Update gate decide karta hai final memory kitni badlegi. Relevance gate decide karta hai candidate banate waqt old memory ka kaunsa hissa dekhna hai. Jaise recipe revise karte waqt chef bolta hai: “kal ka masala ignore karo, aaj fresh tadka chahiye.”

Old memory
c⟨t−1⟩→Γᵣ filters
candidate ke liye→c̃⟨t⟩→Γᵤ mixes
final c⟨t⟩
Dhyan rakhna: Γᵤ ≈ 0 ka matlab “zero memory” nahi. Matlab update zero: purani memory ko pass-through karo.
Yaad rakhna: GRU memory pe gate lagata hai. Gate band ho toh important baat lambe time tak safe reh sakti hai.

Dimaag mein aaye sawaal

Vanishing gradient sirf RNN mein hota hai?

Nahi, deep networks mein bhi ho sakta hai. RNN mein same transition bahut baar repeat hota hai, isliye long sequence pe problem zyada dikhti hai.

Gradient clipping vanishing ko bhi solve karta hai?

Nahi. Clipping exploding gradient ka seat belt hai. Vanishing ke liye GRU/LSTM jaisi memory path help karti hai.

GRU mein a⟨t⟩ aur c⟨t⟩ alag hain?

Simplified GRU mein aksar hidden state aur memory ko same treat karte hain. LSTM mein cell state aur hidden output clearly alag hote hain.

✍️ Ab tumhari baari (pehle khud socho, phir answer kholna)

Γᵤ = 0.1, c̃ = 0.9, c old = 0.4. c new?

0.1×0.9 + 0.9×0.4 = 0.09 + 0.36 = 0.45.

Gate Γᵤ ≈ 0 ho toh GRU kya kar raha hai?

Mostly purani memory yaad rakh raha hai, nayi candidate se overwrite nahi kar raha.

Exploding gradient ka quick practical fix?

Gradient clipping: gradient norm ko threshold ke andar rakhna.
