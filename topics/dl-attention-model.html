Encoder-decoder mein last hidden state poora input sentence carry karta hai. Par 30-word sentence hua to?

Wahi problem. Jaise tum dost ki 2 minute ki voice note sunke end mein sirf ek word yaad rakho — unfair hai na?

To decoder ko input sentence dobara dekhne do?

Exactly. Har output word banate waqt decoder source sentence ke relevant parts pe attention deta hai. “15 August 1947” translate karte waqt date wale tokens pe zyada dhyan.

Lambe sentences pe plain seq2seq kyu thak jaata hai

Plain encoder-decoder input ko ek fixed-size vector mein squeeze karta hai. Short sentence mein chal jaata hai. Long sentence mein start ki details bottle-neck mein dab sakti hain. Isi wajah se length badhne par translation quality, BLEU jaise scores, gir sakte hain.

Plain seq2seqPoora input ek summary vector mein. Decoder ko original words directly nahi dikhte.
Attention modelDecoder har step pe input positions ko weights deta hai. Jahan zaroorat, wahan zyada dhyan.

Insaani translator wali aadat

Human translator poora paragraph ek baar padh ke blank page pe nahi likhta. Woh tukdon mein dekhta hai: subject, verb, date, place. Attention bhi wahi karta hai. Output ka t-th word banate waqt input ke t′ positions ko score deta hai.

Bidirectional encoder ke features a⟨t′⟩

Encoder ko bidirectional RNN bana do. Har source position t′ pe feature a⟨t′⟩ milega, jisme left aur right dono context ka taste hai. “bank” word ke aas-paas “river” hai ya “loan”, BRNN feature mein clue aa jaata hai.

a⟨t′⟩ = [forward hidden⟨t′⟩, backward hidden⟨t′⟩]
  • t′ = source sentence ka position
  • a⟨t′⟩ = us position ka context-aware feature

Attention weights α⟨t, t′⟩: softmax se sum 1

Decoder output step t pe har source position t′ ko ek score e⟨t, t′⟩ deta hai. Phir softmax se weights bante hain. Saare α⟨t, t′⟩ ka total 1 hota hai, jaise attention ka 100% budget.

Source wordscore e⟨t,t′⟩softmax weight α⟨t,t′⟩
kal10.245
Delhi20.665
gaya00.090
Total0.245 + 0.665 + 0.090 = 1.000

Output word agar “Delhi” ya place-related hai, middle word ko sabse zyada weight milna natural hai.

c⟨t⟩ = Σt′ α⟨t, t′⟩ a⟨t′⟩
  • c⟨t⟩ = decoder step t ka context vector
  • α⟨t,t′⟩ = source position t′ pe kitna dhyan
  • a⟨t′⟩ = encoder ka feature us source position pe

e⟨t, t′⟩ ka chhota network

Score e manually nahi likhte. Ek chhota neural network input leta hai: previous decoder state s⟨t−1⟩ aur source feature a⟨t′⟩. Output ek scalar score hota hai. Ye score bolta hai: “is decoder moment pe ye source word kitna useful?”

s⟨t−1⟩
decoder ka mood+a⟨t′⟩
source feature→small NN→e⟨t,t′⟩
import numpy as np
scores = np.array([1.0, 2.0, 0.0])
weights = np.exp(scores) / np.exp(scores).sum()
A = np.array([[1, 0], [0, 2], [3, 1]])
context = weights @ A   # weighted average of encoder features
print(weights.round(3), context.round(3))

Quadratic cost: har output, har input ko dekhta hai

Agar source length Tx hai aur output length Ty, attention scores roughly Tx × Ty bante hain. 10 input aur 12 output ho to 120 score. 1000 aur 1000 ho to 1,000,000. Isliye attention powerful hai, par cost ka dhyan rakhna padta hai.

Dhyan rakhna: Attention weight high hona explanation jaisa dikhta hai, par hamesha perfect human explanation nahi hota. Ye model ka internal routing signal hai, court ka evidence nahi.
Yaad rakhna: Attention decoder ko fixed summary se azaadi deta hai; har output step source ke useful words ka weighted mix banata hai.

Dimaag mein aaye sawaal

Attention RNN ko replace karta hai?

Is page wale model mein nahi. Encoder/decoder RNN abhi bhi hain, attention unke beech smart lookup jaisa hai. Transformer mein self-attention RNN ko mostly replace kar deta hai.

α weights negative ho sakte hain?

Softmax ke baad nahi. Weights positive hote hain aur sum 1 hota hai. Raw score e negative ho sakta hai.

Date format example mein attention kaise help karta?

Output “1947” banate waqt model input ke “1947” token pe high weight de sakta hai; output “August” ke liye “August” pe. Isse order change karna easy hota hai.

✍️ Ab tumhari baari (pehle khud socho, phir answer kholna)

Scores [0, 0] ka softmax kya hoga?

Donon equal hain. e⁰ = 1, total 2. Weights = [1/2, 1/2] = [0.5, 0.5].

Agar Tx = 40 aur Ty = 30, attention scores kitne?

40 × 30 = 1200 scores.

Context vector c⟨t⟩ kis cheez ka weighted average hai?

Encoder features a⟨t′⟩ ka, jahan weights α⟨t,t′⟩ batate hain kis source position pe kitna dhyan hai.
