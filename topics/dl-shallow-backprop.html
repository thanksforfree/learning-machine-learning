Pehle feeling pakdo: output error peeche bhejna hai, hidden layer ko batana hai ki tumhara contribution kitna tha.

W[2]ᵀ kyun aata hai?

Forward mein hidden se output gaya tha W[2] ke through. Backward mein usi road ka ulta direction chahiye, isliye transpose.

Zero initialization mujhe clean lagti thi. Random numbers messy lagte hain.

Clean par dangerous. Agar sab neurons same start karein, sab same seekhenge. Team mein sab log same answer bol rahe hon to team ka fayda gaya.

Small random kyu, large random kyu nahi?

Large values sigmoid/tanh ko saturation mein dhakel sakti hain. Small random: alag bhi, calm bhi.

2-layer network ke backprop equations

Assume hidden activation tanh hai aur output sigmoid. Forward cache mein Z[1], A[1], Z[2], A[2] rakhe the. Ab gradients:

dZ[2] = A[2] − Y dW[2] = (1/m) dZ[2] A[1]ᵀ db[2] = (1/m) sum(dZ[2], axis=1, keepdims=True) dZ[1] = W[2]ᵀ dZ[2] * g′(Z[1]) dW[1] = (1/m) dZ[1] Xᵀ db[1] = (1/m) sum(dZ[1], axis=1, keepdims=True)
  • * = element-wise multiply
  • g′ = hidden activation ka derivative
  • keepdims bias ko column shape mein rakhta hai

dZ[1] ka matlab

W[2]ᵀ dZ[2] output error ko hidden neurons mein baantta hai: kis hidden neuron ne output ko kitna influence kiya. Phir * g′(Z[1]) check karta hai ki hidden activation us point pe slope de raha tha ya gate band tha. ReLU negative side pe ho to gate 0.

Gradient descent ka poora loop

Initialize→Forward→Cost→Backward→Update
for i in range(num_iterations):
    A2, cache = forward(X, parameters)
    cost = compute_cost(A2, Y)
    grads = backward(parameters, cache, X, Y)
    parameters = update(parameters, grads, learning_rate)

Zero initialization se symmetry problem

Agar W[1] ke saare weights zero hain, hidden layer ke saare neurons same z, same a, same gradients paayenge. Update ke baad bhi same rahenge. Random init × 0.01 kyu?

Randomness neurons ki symmetry todti hai. 0.01 se multiply karke values chhoti rakhte hain, taaki tanh/sigmoid start mein saturate na ho. Agar z bahut bada positive/negative ho gaya, derivative tiny ho jaata hai, training slow.

W[1] = np.random.randn(n_h, n_x) * 0.01 b[1] = np.zeros((n_h, 1))

  • b zero okay hai, kyunki W randomness symmetry tod chuki hai

Shape se equations ko sanity-check karo

Equations yaad na bhi ho, shapes tumhe guide kar sakte hain. dW[2] ko W[2] jaisa banana hai. Agar W[2] shape (1, n_h) hai, to dZ[2] (1, m) ko A[1]ᵀ (m, n_h) se multiply karna natural hai.

FormulaShape resultMatch?
dZ[2] A[1]ᵀ(1,m)×(m,n_h)=(1,n_h)W[2] jaisa
dZ[1] Xᵀ(n_h,m)×(m,nₓ)=(n_h,nₓ)W[1] jaisa
Dhyan rakhna: Logistic regression mein zero W okay tha, neural network hidden layers mein nahi. Dono ko mix mat karna.
Yaad rakhna: Backprop error ko layer by layer baantta hai; random small weights neurons ko alag-alag kaam seekhne ka mauka dete hain.

Dimaag mein aaye sawaal

Bias random kyu nahi?

Kar sakte ho, par zaroorat nahi. W random hai to neurons already different hain. Bias zero simple aur safe start hai.

0.01 hamesha best scale hai?

Nahi. Ye shallow tanh networks ke liye simple start hai. Deep networks mein He/Xavier initialization better hoti hai.

Shape check kaise karun?

dW[1] ka shape W[1] jaisa, db[1] ka b[1] jaisa. Har layer pe assert laga do.

Random seed lagana chahiye?

Learning/debugging mein haan, taaki results repeat ho sakein. Production experiments mein multiple seeds try karna bhi useful hota hai.

Large random weights saturation kaise laate hain?

Large weights se z bada positive ya negative ho sakta hai. Sigmoid/tanh edges pe flat ho jaate hain, derivative tiny, gradients slow.

✍️ Ab tumhari baari (pehle khud socho, phir answer kholna)

A[2]=0.65, Y=1. dZ[2]?

dZ[2] = 0.65 − 1 = −0.35.

W=0.4, dW=0.8, α=0.05. New W?

0.4 − 0.05×0.8 = 0.36.

Zero W[1] se hidden neurons alag kyu nahi seekhte?

Sabko same input, same activation, same gradient milta hai. Symmetry break hi nahi hoti.
