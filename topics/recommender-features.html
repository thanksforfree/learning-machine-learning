Pehla tareeka: har movie ke features pata hon

Maan lo har movie ke 2 features diye hain: x₁ = kitni romance, x₂ = kitni action (0–1).

Ab har user ke liye ek chhota linear regression! Riya ke apne weights w aur b. Predicted rating = w · x + b. Riya ka w = [5, 0] (romance pe 5, action pe 0), b = 0.

Moviex (romance, action)Riya ka predicted rating = 5·romance + 0·action
Pyaar Ka Safar[0.9, 0.0]4.5
Toofan Express[0.1, 1.0]0.5 → mat dikhao
Nayi movie “Ishq 2”[0.95, 0.1]4.75 → suggest karo ✓
Riya ki cost = (1/2) × Σ (jin movies ko rate kiya) (w·x + b − asli rating)² + (λ/2) Σ w²
  • Sirf un movies pe galti gino jahan rating hai (khaali “?” ignore).
  • Har user ka apna chhota model. Sab users ki cost jod ke ek saath gradient descent.

Cost ka data part = 1/2 × (0.25 + 0.25) = 0.25. Question mark pe prediction nikal sakta hai, par training galti nahi ginti kyunki sach rating pata hi nahi.

Cold start hint: Agar naye user ne kuch rate nahi kiya, content features ya popular items se start karna padta hai. Sirf ratings table kaafi nahi.

Regularization rating ko tame rakhta hai

Agar user ne sirf ek movie ko 5 diya, model uske weights ko extreme bana sakta hai. λ bolta hai: “bhai, thoda shaant.”

Recommenders sparse hote hain, isliye regularization overfitting se bachane mein kaafi kaam aata hai.

Beginner checkpoint: “?” ko zero mat banao. Zero ek real dislike rating hai; “?” ka matlab unknown. Dono mix kar diye to recommender ulta seekhega.

Ratings table sparse hoti hai, isliye “unknown” ko ignore karna important hai. Unknown ko 0 treat kiya to model sochega user ne movie dekhi aur dislike ki, jo sach nahi hai.

Yaad rakhna: Movie features pata hon to har user ke liye ek chhota linear regression — rating = w·x + b.

Dimaag mein aaye sawaal

Movie ke “romance 0.9” jaise features kaun likhega?

Yahi problem hai! Hazaaron movies ke liye manually likhna mushkil, aur kaunse features matter karte hain pata bhi nahi. Agla topic (collaborative filtering) ye features khud seekh leta hai.

0 rating aur ? mein farak?

0 = dekha aur bilkul pasand nahi aaya (information hai!). ? = dekha hi nahi (koi information nahi). Training mein sirf rated khaane gine jaate hain.

Ratings ko 0–5 hi rehne dein ya normalize karein?

Often normalize karte hain, especially collaborative filtering mein. Scale manageable hota hai aur naye users/items ke defaults better hote hain.

Movie feature manually galat ho to?

Prediction bhi galat ho sakti hai. Agar “action” movie ko romance tag kar diya, romance lovers ko recommend ho jaayegi. Feature quality matters.

✍️ Ab tumhari baari (pehle khud socho, phir answer kholna)

User w = [0, 4], b = 1. Movie x = [0.2, 0.9]. Predicted rating?

0 + 3.6 + 1 = 4.6.

“?” wale khaane cost mein gine jaate hain?

Nahi, sirf rated khaane.
