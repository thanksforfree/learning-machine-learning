Agar movie ke features pata hi na hon? Har movie ko “romance 0.9” kaun tag karega?

Exactly, manually tag karna dard hai. Ulta socho. Pichle page pe features se user weights seekhe. Agar users ke weights pata hote, to ratings dekh ke movie ke features ka andaaza laga sakte the! Riya (romance-lover) ne 5 diya, Neha (action-lover) ne 0 — movie romance wali hogi.

Par dono hi nahi pata!

Yahi jaadu hai: dono ko ek saath seekho. User weights w, b aur movie features x — sab random se shuru, aur gradient descent sabko ek saath sudhare. Bahut saare users ki ratings milke har movie ki “personality” bana deti hain. Isliye naam hai collaborative filtering — sab users milke (collaborate karke) ek doosre ki madad karte hain.

Cost = (1/2) Σ (jahan rating hai) (wᵘ·xᵐ + bᵘ − rating)² + (λ/2) Σ w² + (λ/2) Σ x²
  • u = user, m = movie. Galti sirf rated khaanon pe.
  • Ab gradient descent w, b aur x — teeno ko update karta hai.
  • Seekhe hue features ka naam nahi hota (“romance” wagairah) — bas numbers jo prediction mein kaam karte hain. Thoda mysterious, par useful.
Random w, b, x→Predicted ratings→Asli ratings se galti→w, b, x teeno sudharo↻

Binary labels — star nahi, sirf “pasand/nahi”

Aksar star ratings nahi hoti, bas behaviour hota hai:

Platform1 (engaged)0 (not engaged)?
Online shopKharidaDikhaya, nahi kharidaDikhaya hi nahi
Video app30 sec se zyada dekhaTurant skipDikhaya hi nahi

Tab Module 1 ki tarah hi: linear se logistic pe jao. Chance = sigmoid(w·x + b), aur cost = log loss. Idea wahi, bas output rating ke bajay 0–1 ka chance: “ye user engage karega?”

Dono side seekhne ka tiny example

Dono random se shuru honge to system ko pata kaise chalega kaun romance hai?

Ek rating akeli weak signal hai. Par bahut users ki ratings ek pattern banati hain. Jo users same movies ko high rate karte hain, unke taste vectors paas aate hain; jo movies same users ko pasand aati hain, unke item vectors paas aate hain.

Suppose sirf 1 feature seekhna hai. Prediction = wᵘ × xᵐ + bᵘ, b abhi 0.

Riya / Romance film1.02.02.05w ya x badhao

Numbers ka naam “romance/action” nahi diya gaya. But gradient descent aise values dhundhta hai jahan observed ratings match ho jaayein. Hidden pattern khud emerge hota hai.

Dhyan rakhna: Learned features ko human names dena tempting hai, par guarantee nahi. Kabhi feature 7 “romance + old movies + Hindi” ka mix ho sakta hai.

Beginner checkpoint: Collaborative filtering tab shine karta hai jab users aur items ke beech enough interactions hon. Bahut sparse table mein cold start aur noise dono badh jaate hain.
Yaad rakhna: Collaborative filtering = user tastes aur item features dono ratings se ek saath seekhna.

Dimaag mein aaye sawaal

Kitne features (x ki length) rakhein?

Ye tumhara choice hai — jaise 10, 50, 100. Zyada = zyada detail pakad sakta hai par zyada data chahiye. CV set pe try karke chuno.

Kya ye linear regression hi hai?

Har ek user ke liye dikhne mein haan, par farak ye hai ki features x bhi seekhe ja rahe hain. Normal linear regression mein features fixed hote hain; yahan user taste aur movie personality dono ban rahe hain.

Bias bᵘ kyu chahiye?

Kuch users naturally high ratings dete hain, kuch strict hote hain. bᵘ user ka personal rating level pakadta hai, taaki w aur x taste pattern pe focus karein.

Collaborative filtering privacy sensitive hai?

Haan. Ratings/clicks user behaviour hote hain. Real systems ko privacy, consent, retention aur misuse pe serious hona padta hai.
