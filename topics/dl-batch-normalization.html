Inputs normalize karna samajh aaya. Par hidden layer ke andar bhi normalize? Network khud manage nahi kar sakta?

Kar sakta hai, par har layer ka input training ke dauraan badalta rehta hai. Jaise tum cricket practice kar rahe ho aur bowler har over pitch hi badal de.

To har layer ko stable pitch deni hai?

Bilkul. Batch normalization hidden layer ke numbers ko standard range mein laata hai, phir network ko permission deta hai ki “agar chaho to scale/shift khud choose kar lo.”

Normalize karke phir change karne ki permission? Thoda ulta nahi?

Pehli baar sabko ulta lagta hai. Normalize stability ke liye, γ aur β flexibility ke liye.

Hidden layer ke Z ko normalize karna

Batch norm aam taur pe activation se pehle wale Z values pe lagaya jaata hai. Ek mini-batch lo, us batch mein har neuron ka mean aur variance nikaalo, phir normalize.

μ = average(Z) σ² = average((Z − μ)²) Z_norm = (Z − μ) / √(σ² + ε) Z_tilde = γZ_norm + β
  • μ, σ² mini-batch se nikle mean aur variance
  • ε tiny safety number
  • γ scale parameter, network seekhta hai
  • β shift parameter, network seekhta hai

Normalize ke baad values mean 0 aur variance 1 ke aas-paas. Phir γ, β se network decide kar sakta hai ki is neuron ko actually kis scale pe rakhna hai.

γ aur β: network ko freedom

Agar hum sirf normalize kar dein to har layer ko mean 0, variance 1 pe force kar denge. Kabhi network ko different scale chahiye hota hai. γ aur β learnable knobs hain. Agar original distribution useful hai, network γ aur β se uske paas wapas bhi ja sakta hai.

Network mein kaise fit hota hai, aur b bekaar kyu

Layer mein pehle Z = WA + b. Batch norm Z ka mean subtract karta hai. b har example mein same shift add karta hai, aur mean subtract hote hi woh shift cancel ho jaata hai. Isliye batch norm wali layer mein b ko omit karna common hai; β shift ka kaam kar leta hai.

Z = W @ A_prev              # b optional, batch norm shift hata dega
mu = np.mean(Z, axis=1, keepdims=True)
var = np.mean((Z - mu) ** 2, axis=1, keepdims=True)
Z_norm = (Z - mu) / np.sqrt(var + 1e-8)
Z_tilde = gamma * Z_norm + beta
A = relu(Z_tilde)

Kaam kyu karta hai?

Covariate shift kamPichhli layers badalti hain to baad ki layer ka input distribution hilta hai. Batch norm is hilaav ko control karta hai.
Stable trainingActivations extreme zone mein kam jaate hain. Gradients zyada manageable.
Hyperparameters forgivingLearning rate aur initialization ke liye model thoda kam nakhre karta hai.
Thoda regularizationMini-batch stats noisy hote hain, isliye har example ko halka random environment milta hai. Dropout ka replacement nahi, par help karta hai.

Test time pe mini-batch stats nahi

Training mein batch ke μ, σ² use hote hain. Test time pe single example aa sakta hai; uska batch mean nikaalna weird hoga. Isliye training ke dauraan μ aur σ² ke moving averages maintain karte hain, aur test time pe wahi use karte hain.

Dhyan rakhna: Training mode aur inference mode mix mat karo. Test/prediction ke waqt current batch stats use kar liye to output batch ke doosre examples pe depend karega — bahut annoying bug.
Yaad rakhna: Batch norm hidden Z ko normalize karta hai, γ/β se flexibility deta hai, aur test time pe stored moving averages use karta hai.

Dimaag mein aaye sawaal

Batch norm dropout ki jagah le sakta hai?

Kabhi-kabhi overfitting thoda kam karta hai, par iska main kaam optimization stable karna hai. Strong overfitting ho to L2, dropout, data augmentation alag se socho.

Activation se pehle ya baad?

Common choice Z pe, activation se pehle. Kuch architectures activation ke baad bhi variants use karte hain. Beginner mental model: Z normalize, phir activation.

Mini-batch size bahut chhota ho to?

Stats noisy ho jaate hain. Batch norm ka benefit kam ho sakta hai. Tab layer norm/group norm jaise alternatives bhi use hote hain, par abhi batch norm ka core idea pakdo.

✍️ Ab tumhari baari (pehle khud socho, phir answer kholna)

Z = [1, 3, 5] ka mean kya?

(1 + 3 + 5)/3 = 3.

Normalize ke baad γ = 1, β = 0 ho to Z_tilde kya hota hai?

Z_norm hi. Scale 1 aur shift 0 kuch change nahi karte.

Batch norm wali layer mein b kyu often remove kar dete hain?

Mean subtraction b ka constant shift cancel kar deta hai. Learnable β shift ka kaam kar leta hai.
