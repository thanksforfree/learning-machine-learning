Binary classification mein sigmoid tha. Par agar classes 10 hain, jaise digit 0 se 9?

Tab ek hi haan/na ka button kaafi nahi. Har class ko ek score do, phir scores ko probabilities mein badlo.

Scores matlab marks? Jiske zyada marks, woh answer?

Haan, par marks ko probability banana hai taaki total 1 ho. Ye kaam softmax karta hai.

Hardmax kyu nahi — bas highest ko 1, baaki 0?

Training ko smooth feedback chahiye. Softmax bolta hai: “ye class likely hai, par doosri thodi possible hai.”

C classes, output layer mein C units

Agar classes 5 hain, output layer mein 5 units. Har unit ek raw score z_c deta hai. Score probability nahi hota; negative bhi ho sakta hai. Softmax scores ko positive probabilities mein convert karta hai jinka sum 1 hota hai.

t_c = e^{z_c} ŷ_c = t_c / Σ_j t_j
  • z_c = class c ka raw score
  • e^{z_c} = score ko positive number banana
  • Σ_j t_j = sab exponentials ka total
  • ŷ_c = class c ki predicted probability

Highest score samosa ka tha, probability bhi highest. Par model thoda chance dosa ko bhi de raha hai. Ye softness training mein useful hai.

Bina hidden layer ke linear boundaries

Softmax regression agar direct input se output tak hai, to har class ka score linear hota hai. Isliye boundaries straight lines/planes hoti hain. Hidden layers add karo to network complex shapes bana sakta hai, par last layer softmax hi probabilities banati hai.

Hardmax vs softmax

HardmaxHighest class ko 1, baaki 0. Final prediction ke liye theek, training ke liye rough.
SoftmaxHar class ko probability. Loss bata sakta hai ki galti kitni confident thi.

Loss: one example pe cross-entropy

Label one-hot hota hai. Agar true class samosa hai, y = [1, 0, 0]. Loss sirf true class ki probability pe focus karega.

L = −Σ_c y_c log(ŷ_c)
  • y_c one-hot label, true class pe 1
  • ŷ_c softmax probability
  • Agar true class probability high, loss low

Upar samosa probability 0.659 thi. Loss = −log(0.659) = 0.417. Agar model true class ko 0.05 chance deta, loss 2.996 hota. Confident galti ki saza badi.

Cost J = saare examples ke losses ka average. Mini-batch mein bhi same idea: batch ke examples ka average.

Gradient: dZ = Ŷ − Y

Softmax + cross-entropy ka gradient surprisingly clean hai. Prediction minus label.

z = np.array([2.0, 1.0, 0.1])
t = np.exp(z)
y_hat = t / np.sum(t)
y = np.array([1, 0, 0])
dz = y_hat - y   # softmax + cross-entropy gradient

C = 2 pe logistic regression hi

Agar classes sirf 2 hain, softmax output do probabilities dega. Ek class ki probability p hai, doosri 1 − p. Ye sigmoid/logistic regression ke barabar idea hai. Isliye binary mein sigmoid convenient, multiclass mein softmax convenient.

Dhyan rakhna: Softmax tab use karo jab classes mutually exclusive hon — ek image sirf ek digit hai. Agar ek photo mein dog aur car dono ho sakte hain, har label ke liye alag sigmoid chahiye, softmax nahi.
Yaad rakhna: Softmax scores ko probabilities banata hai, cross-entropy true class ko reward/punish karti hai, aur gradient simply Ŷ − Y hota hai.

Dimaag mein aaye sawaal

Softmax mein e kyu use hota hai?

eᶻ positive hota hai aur score differences ko nicely probability differences mein badalta hai. Plus calculus clean ho jaata hai.

Scores mein constant add karun to probabilities badlengi?

Nahi. [2, 1, 0.1] aur [12, 11, 10.1] ka softmax same hoga, kyunki relative differences same hain. Code mein stability ke liye max subtract karte hain.

One-hot label kya hota hai?

C classes ki list jisme true class pe 1, baaki 0. Jaise 3 classes mein class 2 true ho to [0, 1, 0].

✍️ Ab tumhari baari (pehle khud socho, phir answer kholna)

Scores [0, 0, 0] ka softmax?

Sab e⁰ = 1. Total 3. Probabilities = [1/3, 1/3, 1/3].

True class probability 0.8 ho to loss −log(0.8) approx?

−log(0.8) ≈ 0.223.

Ek photo mein multiple labels possible hain. Softmax ya sigmoids?

Alag-alag sigmoids, kyunki classes mutually exclusive nahi.
