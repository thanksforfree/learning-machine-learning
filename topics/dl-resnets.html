Deep network better hona chahiye na? Phir 100 layers laga do, kaam khatam.

Kaash! Plain network mein layers badhane se kabhi-kabhi training error hi badhne lagta hai. Matlab model training data bhi achha fit nahi kar pa raha.

Par zyada layers ke paas option to hai ki extra layers kuch na karein?

Theory mein haan. Practice mein “kuch na karna” learn karna bhi mushkil pad sakta hai. ResNet ne shortcut diya: agar layer kuch useful na seekhe, input ko seedha aage bhej do.

Shortcut jaise exam mein rough work skip?

Thoda. Agar beech ka block help nahi kar raha, identity raasta available hai. Isi se very deep networks trainable bane.

Residual block ka core idea

Normal block input a[l] leta hai, kuch conv/ReLU karta hai, aur output deta hai. Residual block us output mein original input ko add kar deta hai.

a[l+2] = g( z[l+2] + a[l] )
  • a[l] = block ka input activation
  • z[l+2] = do layers ke baad ka linear output
  • + = skip connection; input seedha add
  • g = activation, jaise ReLU

Plain network mein training error badh kyu sakta hai?

Agar 20-layer plain network train ho raha hai, to 56-layer plain network at least utna achha hona chahiye — extra layers identity ban sakti hain, right? Problem ye hai ki optimizer ko exact identity mapping dhundhna easy nahi hota.

Deep plain network mein gradients ko bahut layers se guzarna padta hai. Kabhi signal weak hota hai, kabhi optimization awkward. Result: training data pe bhi error badh sakta hai. Ye overfitting nahi; ye optimization problem hai.

ResNet kyu kaam karta hai: identity easy bana do

Residual block ko aise socho:

output = ReLU( F(a[l]) + a[l] )
  • F(a[l]) = block ke conv layers jo extra change seekhte hain
  • Agar useful change nahi chahiye, F(a[l]) ≈ 0 seekhna relatively easy
  • Tab output ≈ ReLU(a[l]) — input ka signal aage nikal gaya

Matlab block ko poori mapping learn nahi karni. Sirf “input mein kya correction add karna hai” learn karna hai. Jaise mummy ki dal already achhi hai; tumhe bas thoda namak adjust karna hai, poori dal dobara banani nahi.

Dimensions match: same conv ya W_s

Addition tabhi possible hai jab shapes same hon. Agar z[l+2] aur a[l] dono 28×28×64 hain, seedha add. Par agar block channels 64 se 128 kar raha hai ya stride se size half kar raha hai, shortcut ko bhi transform karna padega.

a[l+2] = g( z[l+2] + W_s a[l] )
  • W_s = shortcut projection, often 1×1 convolution
  • Example: 1×1 conv, 64 input channels, 128 output channels
  • Parameters without bias = 1 × 1 × 64 × 128 = 8,192

Same conv padding spatial size preserve kar sakta hai. Projection shortcut shape ko match karata hai. Add operation ko shape drama bilkul pasand nahi.

Photos pe ResNet ka dhaancha

Typical ResNet pehle ek conv layer se basic features nikalta hai, phir residual blocks ke groups. Har group mein spatial size kabhi half hota hai, channels double. End mein global average pooling aur softmax.

Image→Conv→Residual blocks→Global avg pool→Softmax
def residual_block(x):
    shortcut = x
    z = conv_relu(x)
    z = conv(z)
    return relu(z + shortcut)  # shapes same honi chahiye
Dhyan rakhna: Skip connection concatenate nahi karta; ResNet mein usually add karta hai. Add ke liye shapes exactly match honi chahiye.
Yaad rakhna: ResNet block poori nayi mapping nahi, input par correction seekhta hai. Shortcut deep network ko “kuch na karne” ka easy option deta hai.

Dimaag mein aaye sawaal

Shortcut se model cheating kar raha hai?

Nahi. Shortcut bhi architecture ka part hai. Agar block useful feature seekhta hai to F(a) add hota hai; agar nahi, signal safe aage jaata hai.

ResNet mein ReLU addition se pehle ya baad mein?

Original blocks mein addition ke baad ReLU common tha. Baad mein pre-activation variants aaye. Beginner level pe main idea: skip path add hota hai.

Transformers mein bhi skip connection hota hai?

Haan. Residual/skip connection ka idea CNN se bahar bhi bahut useful nikla. Deep Transformer blocks mein bhi residual paths hote hain.

✍️ Ab tumhari baari (pehle khud socho, phir answer kholna)

z = [−2, 3, 1], shortcut a = [5, −1, 2]. ReLU(z+a) kya?

z+a = [3, 2, 3]. ReLU same rakhega. [3, 2, 3].

1×1 shortcut projection: 256 input channels se 512 output channels. Bias ignore karo. Params?

1 × 1 × 256 × 512 = 131,072.

Plain deep network ka training error depth badhne pe badh raha hai. Ye high variance hai?

Nahi zaroori. Training error hi badh raha hai, to ye mostly optimization problem hai; ResNet shortcut help kar sakta hai.
