Regularization actually karta kya hai?

Overfit wala wiggly curve dekho — uske kuch weights bahut bade hote hain (jaise w₄ = 5000). Bade weights = curve ko pagal jaisa modne ki power.

Regularization bolta hai: “Saare features rakh lo, koi baat nahi. Par kisi weight ko bina wajah bada kiya to cost mein penalty lagegi.” Ab model khud balance karta hai — galti bhi kam, weights bhi chhote.

Penalty kitni?

Woh λ (lambda) decide karta hai. Cricket coach socho: “Shots khelo, par har ball pe six maarne ki koshish mat karo.” λ = coach kitna strict hai.

Agar coach bahut strict ho gaya?

Phir batter bas defend karega — model flat ho jayega, underfit. Regularization mein bhi balance chahiye, jaise chai mein chini.

J = (purana galti wala cost) + (λ / 2m) × (w₁² + w₂² + … + wₙ²)
  • Pehla hissa: data ko achhe se fit karo.
  • Doosra hissa: weights chhote rakho.
  • b ko usually is penalty mein nahi daalte.

Ab model ko sirf training galti nahi, bade weights ka rent bhi pay karna padta hai.

Gradient descent pe iska asar

wⱼ = wⱼ × (1 − αλ/m) − α × (normal slope)
  • (1 − αλ/m) jaise 0.9998 hota hai. Matlab har step pe weight ko thoda sa sikod do, phir normal update. Isliye isko “weight decay” bhi kehte hain.

Chhota example: α = 0.01, λ = 1, m = 5, w = 10, normal slope = 3. Pehle weight 10 × 0.998 = 9.98 hua, phir 0.03 normal update ghata: naya w ≈ 9.95. Dheere-dheere weight ki hawa nikalti rehti hai.

Yahi same penalty logistic regression pe bhi lagti hai — wiggly decision boundary ko smooth karne ke liye.

Module 1 ki badi picture: Problem dekho (number ya category?) → model chuno (linear ya logistic) → cost define karo (squared error ya log loss) → gradient descent se cost ghatao → overfitting pe nazar rakho (regularization, zyada data). Yahi flow aage har model mein repeat hoga.
Yaad rakhna: Regularization model ko “fit karo, par drama mat karo” bolta hai — useful weights rakho, bekaar bade weights chhote karo.

Dimaag mein aaye sawaal

λ ki sahi value kaise choose karein?

Kuch values try karo (0, 0.01, 0.1, 1, 10…) aur har ek ko alag rakhe validation data pe check karo. Jo best, woh lo. Module 2 mein ye detail mein hai.

Features hi hata dein, regularization ki kya zaroorat?

Feature hataoge to uski information poori chali gayi. Regularization softly weight chhota karta hai — useful feature ka thoda asar bacha rehta hai.

b ko penalty mein kyu nahi daalte?

b sirf poori line ko upar-neeche khiskata hai, curve ko wiggly nahi banata. Daal bhi do to zyada farak nahi padta.

L1 aur L2 regularization same hain?

Nahi. Yahan L2 hai: squares add hote hain, weights smoothly chhote hote hain. L1 absolute values add karta hai aur kuch weights ko exact zero tak dhakel sakta hai.

Regularization lagane ke baad cost graph kaise dekhein?

Training ke waqt jo cost optimize ho rahi hai usme penalty include karo. Sirf old error plot karoge to lag sakta hai model kharab ho raha hai, jabki woh weights control kar raha hota hai.
