MathsSlope, derivative aur chain rule

Network mein hazaaron weights hain. Kaunsa weight galti ka kitna zimmedar hai, ye kaise pakdenge?

Cricket team match haar gayi. Coach scoreboard se peeche sochta hai: “score kam kyu? middle order dab gaya; pressure kyu? opener jaldi out.” Result se shuru karke zimmedari har player tak pahunchti hai. Backpropagation bhi output ki galti se peeche har layer, har weight tak jaake poochta hai — “bhai, tumhara kitna hissa tha?”

Chhota sa example (bina calculus ke)

x = 2, weight w = 3, sahi answer y = 5. Prediction f = w × x = 6. Galti d = f − y = 1. Cost J = d² / 2 = 0.5.

TareekaHisaabSlope (J pe w ka asar)
Thoda sa hila ke dekhow = 3.001 → f = 6.002 → d = 1.002 → J = 0.502. J 0.002 badha jab w 0.001 badha2
Chain (backprop)J pe d ka asar = d = 1
d pe f ka asar = 1
f pe w ka asar = x = 2
Multiply: 1 × 1 × 2		2 — same!

Bas! Yehi chain multiplication backprop hai. Haan, pehli baar thoda jaadu lagta hai, par idea simple hai: har chhote step ka asar multiply karo. Hazaaron weights ke liye ye ek backward pass mein efficiently ho jaata hai. Phir gradient descent (ya Adam) in slopes se weights update karta hai.

Input→Forward: prediction→Loss: kitna galat?→Backward: zimmedari baanto→Weights update↻

Adam optimizer — smart gear

Normal gradient descent mein sab weights ka ek hi α hota hai. Adam thoda smart driver hai: koi weight ek hi direction mein steady ja raha hai to kadam bada; idhar-udhar hil raha hai to kadam chhota. Jaise scooty traffic mein khud speed adjust kare. Zyadatar practical starts mein Adam default choice hai.

EpochPoore training data pe ek chakkar.
Mini-batchEk update ke liye data ka chhota hissa (jaise 32 examples). Fast updates.
Doosri layer types: Dense layer mein har neuron poora input dekhta hai. Convolutional layer mein har neuron input ka bas ek chhota hissa dekhta hai (jaise photo ka ek kona). Kam weights → fast training, kam data mein bhi kaam, overfitting kam.

Backprop ke baad update ka effect

Slope mil gaya, par weight actual mein kitna badalta hai?

Learning rate α uska step size hai. Slope direction aur steepness batata hai; α bolta hai “itna hi kadam lena, bhaagna nahi”.

Wahi example: x = 2, y = 5, shuru w = 3. Prediction 6 tha, slope dJ/dw = 2. Learning rate α = 0.1.

Dhyan rakhna: α bahut bada hua to w target ke aage-peeche uchhal sakta hai. Loss badhne lage to learning rate pe shak karo.

Autodiff ko kaise trust karein?

TensorFlow/PyTorch gradients khud nikaalte hain, par trust blind nahi. Chhote cases pe sanity check kar sakte ho.

Yaad rakhna: Backprop = har weight ka slope nikaalna. Gradient descent/Adam = us slope se weight sudharna.

Dimaag mein aaye sawaal

Backprop aur gradient descent ek hi cheez hain?

Nahi, team-mates hain. Backprop = “kis weight ko kis taraf kitna badlo” (slope) nikaalta hai. Gradient descent/Adam = asal mein badalta hai.

Backprop haath se karna padega?

Nahi. TensorFlow automatic karta hai (isko autodiff kehte hain). Idea samajhna zaroori hai taaki bugs samajh sako.

Mera loss kam hi nahi ho raha. Kya check karun?

Checklist: (1) data aur labels sahi hain? (2) output activation aur loss match karte hain? (3) inputs scaled hain? (4) learning rate theek hai? (5) Sirf 10 examples pe train karke dekho — itne kam pe to model ratt hi lega. Wahan bhi loss na gire to pakka bug hai.

Adam use karun to learning rate matter karta hai?

Haan, matter karta hai. Adam har weight ka step adjust karta hai, par base learning rate α phir bhi overall speed set karta hai. 0.001 common starting point hai.
