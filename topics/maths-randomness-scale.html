Weights random kyu shuru karte hain? Zero se start simple nahi?

Zero se saare neurons same sochenge — jaise group project mein sab ek hi answer copy kar rahe hon. Randomness symmetry todti hai.

Par random kitna bada? Kuch bhi daal dein?

Yahin scale ka game hai. Bahut bada to activations/gradients explode; bahut chhota to vanish.

np.random.randn: mean 0, variance 1

randn normal bell curve se random numbers deta hai: average 0 ke aas-paas, variance 1 ke aas-paas. Matlab typical number −2 se 2 ke beech hoga, kabhi-kabhi bahar bhi.

import numpy as np

np.random.seed(7)                 # same random numbers dobara
W = np.random.randn(3, 2)         # mean 0, variance ~1 source
print(W.shape)                    # (3, 2)
Dhyan rakhna: Random ka matlab uncontrolled nahi. Experiments compare karne ke liye seed set karo, warna har run thoda alag result dega.

Scale karo to variance c² guna hoti hai

Agar random number x ki variance 1 hai, aur tum y = c x banate ho, to variance c² ho jaati hai.

Multiplier cVariance multiplierMeaning
0.20.2² = 0.04Numbers chhote, spread kam
22² = 4Numbers bade, spread 4 guna

n random cheezon ka sum — variance badh jaati hai

Neuron dot product mein kai terms jodta hai: w₁x₁ + w₂x₂ + .... Agar 100 independent terms hain aur har term ki variance 0.01 hai, sum ki variance ≈ 100 × 0.01 = 1. Independent hone par variances add hoti hain; isi idea se weights ki variance ko input count ke hisaab se chhota rakhte hain.

n terms ka sum variance ≈ n × term_variance Stable rakhne ke liye weight variance ≈ 1/n ReLU ke liye common: Var(W) ≈ 2/n
  • Xavier (tanh ke liye): standard deviation ≈ √(1/n).
  • He init (ReLU ke liye): standard deviation ≈ √(2/n).
  • Code: np.random.randn(...) * np.sqrt(2 / n_prev).
n_prev = 100
W_relu = np.random.randn(50, n_prev) * np.sqrt(2 / n_prev)
W_tanh = np.random.randn(50, n_prev) * np.sqrt(1 / n_prev)

Baar-baar multiply: explode vs vanish

Deep network mein signal layer se layer multiply hota rehta hai. Thoda sa 1 se bada number bhi 50 layers mein monster ban sakta hai.

Repeated factor50 baar multiplyFeel
1.1⁵⁰117.39Explode: signal bahut bada
0.9⁵⁰0.00515Vanish: signal almost gayab

Log scale pe random sampling

Learning rate jaise hyperparameters 0.0001 se 1 tak ho sakte hain. Linear random pick karoge to bade numbers zyada milenge. Log scale pe pick karo:

r uniformly choose karo [−4, 0] se α = 10ʳ
  • r = −4 → α = 0.0001
  • r = −2 → α = 0.01
  • r = 0 → α = 1
r = np.random.uniform(-4, 0)
alpha = 10 ** r                 # log scale learning rate

seed = 42
np.random.seed(seed)            # result reproducible

Deep learning mein ye kahan milega?

DL Course 1 ke random initialization page mein, Course 2 ke vanishing/exploding gradients, He/Xavier initialization, hyperparameter tuning, aur dropout randomness mein.

Yaad rakhna: Randomness symmetry todti hai; scale training ko stable rakhta hai. Variance ka hisaab galat hua to deep network ya explode karega ya vanish.

Dimaag mein aaye sawaal

Zero bias rakh sakte hain?

Haan, biases ko zero se start karna common hai. Problem zero weights se hoti hai, kyunki neurons same gradients paate hain.

Seed set karna production mein zaroori?

Debugging aur experiments compare karne mein zaroori. Final training mein bhi reproducibility ke liye useful, par GPU operations kabhi-kabhi phir bhi tiny difference de sakte hain.

He init sirf ReLU ke liye?

Mainly ReLU-family ke liye. tanh/sigmoid ke liye Xavier type scale zyada natural hota hai, kyunki activation behavior alag hai.

✍️ Ab tumhari baari (pehle khud socho, phir answer kholna)

x ki variance 1 hai. y = 0.5x. y ki variance?

Variance multiplier 0.5² = 0.25. Final variance 0.25.

n = 400 inputs. Xavier std roughly?

√(1/400) = 1/20 = 0.05.

r = −3 ho to α = 10ʳ kitna?

10⁻³ = 0.001.
