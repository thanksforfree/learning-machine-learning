Content-based filtering kya alag karta hai? Naam same-same sa lag raha.

Collaborative filtering bolta hai: “tumhare jaise logon ne kya pasand kiya.” Content-based bolta hai: “tumhare baare mein aur movie ke baare mein jo pata hai, usse match karo.” Shaadi.com type scene — dono profiles dekho, phir match score.

User features (xᵘ)Umar, desh, pehle kaunse genres dekhe, average kitne star deta hai, kaunsi language…
Movie features (xᵐ)Genre, release saal, actors, critics rating, average user rating…

Deep learning se match karna — do towers

Do alag neural networks banao. User network: user features lo → ek chhota vector vᵘ (maan lo 32 numbers) — user ki “taste profile”. Movie network: movie features lo → vᵐ (32 numbers) — movie ki “personality”. Match score = vᵘ · vᵐ (dot product). Dono vectors ek jaise → score zyada.

User features→User NN → vᵘ·vᵐ ← Movie NN←Movie features
Score = vᵘ · vᵐ→(ya sigmoid(vᵘ · vᵐ) = like ka chance)

Dono networks ek hi cost (rating ki squared error, ya log loss) se ek saath train hote hain. Output layers ka size same hona chahiye, warna dot product bol dega: “bhai dimensions match nahi.”

Similar movies: vᵐ ek doosre ke paas → movies milti-julti. Ye pehle se (raat ko) calculate karke rakh sakte ho.

Crore items mein se kaise chunein — retrieval & ranking

Lakhon movies, har ek ke liye network chalana slow nahi hoga?

Bahut slow. Isliye do step. Retrieval: jaldi se ~100–500 “shayad achhe” candidates nikaalo — user ki pichhli 10 movies jaisi movies, uske favourite genre ki top movies, uske desh mein trending. Ranking: in chune hue candidates pe hi poora model chalao aur score se sort karo.

1 crore items→Retrieval (fast, rough)→~300 candidates→Ranking (accurate model)→Top 10 dikhao

Zyada candidates retrieve karo to better result mil sakta hai, par system slow hoga. Offline experiments se balance tay karo — user ko achhi recommendation bhi chahiye aur app ko ghoomta hua spinner bhi nahi chahiye.

Recommender ki zimmedari (ethics)

Sochne wali baat: Agar system sirf “zyada click / zyada time” maximize kare to woh clickbait, gussa bhadkane wala ya galat content bhi push kar sakta hai, kyunki log uspe zyada ruk-te hain. Ya sirf zyada paisa dene wale ads upar. Achha design: users ke fayde ko bhi goal mein rakho, harmful content filter karo, aur transparent raho ki cheezein kyu dikh rahi hain.

Dot product ka numeric match score

vᵘ · vᵐ bada matlab match. Par dot product actual mein kya compare karta hai?

Agar user aur movie vector same directions mein high hain, products add hoke score bada. Agar opposite taste hai, score chhota ya negative.

VectorMeaning feel
vᵘ = [2, 0.5, −1]User ko feature 1 pasand, feature 3 avoid
Movie A vᵐ = [1, 1, 0]Feature 1 strong
Movie B vᵐ = [0, 1, 2]Feature 3 strong
MovieScoreReading
A2×1 + 0.5×1 + (−1)×0 = 2.5Good match
B2×0 + 0.5×1 + (−1)×2 = −1.5Bad match

Neural networks ye vectors aise seekhte hain ki clicked/liked items ka score high aur ignored items ka score low ho.

Beginner checkpoint: Retrieval fast aur rough hota hai, ranking slow aur accurate. Large apps dono use karte hain; sirf ranking se crore items scan karna mehenga padega.
Yaad rakhna: Content-based = user aur item features se do networks ke vectors ka dot product; bade catalogue ke liye pehle retrieval, phir ranking.

Dimaag mein aaye sawaal

Collaborative ya content-based — kaunsa better?

Asli systems aksar dono milate hain. Content-based naye items (cold start) ke liye achha kyunki features hain; collaborative chhupe patterns pakadta hai jo features mein nahi.

vᵘ ke 32 numbers ka matlab kya hai?

Koi seedha naam nahi — network ne khud seekha. Bas itna pata hai ki similar taste wale users ke vectors paas-paas hote hain. Thoda “black box” hai, par recommendation kaam ki ho to useful.

TensorFlow mein ye kaise?

Do Sequential networks banao, dono ke outputs ko normalize karke Dot layer se jodo, aur ek Model mein wrap karke compile/fit karo — basic structure Module 2 jaisa hi.

Vectors normalize kyu karte hain?

Normalize karne se dot product zyada angle/similarity jaisa behave karta hai, sirf vector ki length se dominate nahi hota. Retrieval mein ye useful hota hai.
